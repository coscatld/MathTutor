# MathTutor 数迹

MathTutor 是面向学习者的桌面 AI 数学学习与知识探索软件。你可以带着一道题来，先写自己的思路，再寻求提示；也可以带着一个疑问来，从知乎问答中比较解释，回到原文核对。

[产品官网](https://coscatld.github.io/MathTutor/zh/) · [第一次使用](https://coscatld.github.io/MathTutor/zh/docs/user/quick-start/) · [English guide](https://coscatld.github.io/MathTutor/en/)

## 下载与安装

| 平台 | 安装包 | 首次使用 |

打开应用即可尝试基础数学练习。在设置中可以切换中文和 English，或连接自己的模型和知乎知识来源。首次打开的系统提示与文件校验方法见[安装指南](https://coscatld.github.io/MathTutor/zh/docs/user/installation/)和[下载记录](https://github.com/coscatld/MathTutor/releases/tag/desktop-20261118)。

## 学一道题

- **按需要获取帮助。** 先独立作答，遇到困难再看概念提示、下一步或解答。用一道同类新题检查自己能否独立完成。
- **核对数学推理。** 支持范围内的算式、方程和不等式由本地计算核验。缺少条件时，应用会请你补全；需要概念讨论的内容会标明核验范围。
- **安排下一步。** 学习记录区分独立完成、获得提示和看过解答。学习计划结合作答证据、前置知识和你当前指定的目标，帮助选择练习或阅读资料。

## 探索一个问题

在“设置 → 知识来源”连接知乎，然后在聊天中开启“联网”。试着问「分数相加为什么要通分？」或「能用两个来源比较不同的解释吗？」。你可以查看回答引用的片段、作者与原文链接，判断两种解释各自适用的条件。学习画像也能按当前目标推荐阅读材料。 [知识探索指南](https://coscatld.github.io/MathTutor/zh/docs/user/knowledge-exploration/)
