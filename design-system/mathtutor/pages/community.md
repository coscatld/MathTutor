# 社区资源与教学插件

沿用 MASTER 的纸墨、冷蓝、系统中文字体与 Lucide 图标。社区页新增独立功能结构，不改全局视觉语言。

## 信息与交互

- 发现资源：关键词搜索，题库 / 插件类型、学段、收藏 / 已添加筛选；卡片展示实际作者声明、许可、版本、来源与更新状态。卡片可一键导入或下载，文件按钮直接识别已下载的插件与题库；版本与内容完整性检查留在内部，失败不伪造成功收据。
- 我的插件：安装与授权分开，默认停用，可读权限列表与“同意并启用”按钮；配置、运行、升级、停用、卸载和“保存结果”可实际操作，结果保存为可阅读文本。读取失败清掉旧启用卡片，先重新读取再允许运行。
- 社区来源：用户订阅 GitHub Raw 或自定义 HTTPS 目录，显式刷新。失败保留缓存且显示 stale 与错误；删除来源不暗中删除个人资料和插件。
- 创作与分享：题库和教学插件分别建表单。作者可打包当前 Markdown，或选择“组一套练习题”“整理错题”“查看学习变化”，用自然表单调整数量、年级和教学建议。自动生成插件标识，切换用途生成新标识；分享版本与许可收在折叠设置。插件校验只生成下载文件，安装和启用另行决定；未下载修改有离开提示。
- 项目主页、反馈和讨论使用作者提供的 HTTPS 协作链接。当前目录没有社区评分、下载量或虚构作者账户。

## 布局与可访问性

- 三个主分类始终可见，“社区来源”作为次要入口，支持 `?tab=plugins` 等深链接。筛选控件有独立名称，标签和状态允许换行；窄屏不依赖横向滚动。
- 详情为内联阅读区，加载后把焦点放到标题；关闭、刷新、错误重试、原生表单校验均有键盘入口。
- 插件曲线保留所有真实数据点，横轴最多八个刻度，另有完整数据表。独立作答、帮助后和自述分别显示；缺失值为 null / 空态，不能绘成 0% 或 100%。
- 侧栏导航可纵向滚动，在小屏横屏仍能到达全部入口。社区样式独立命名空间，主题和减少动画沿用全局令牌。

## 设计依据与验证

ui-ux-pro-max 的新页查询匹配 Minimalism & Swiss Style；返回的营销 Hero、紫色与英文字体不符合当前学习工作台，因此未采用。针对 `filter search catalog --domain ux`，采用真实匹配的空结果恢复建议和筛选标签换行；React/Next.js 按当前安装文档实现客户端状态与深链接。

前端 234 项通过，生产编译通过；生产 standalone 的 `smoke-community.mjs`、`smoke-learning-support.mjs`、`smoke-creator-workspace.mjs`、`smoke-vault-files.mjs` 全部通过。覆盖桌面、375px、横屏、夜读、减少动画、版本锁、升级权限、无数据与真实序列、导出、创作者校验和插件服务失败恢复。

最终 0.7.0 后端全量 3,006 项通过，11 项可选依赖检查跳过；包含统一文件导入、打包工具与三工作流真实互通、严格元数据、跨用户、Origin、重试和失败补偿检查。真实题库、SQLite、学习事件和文件读写另有后端集成测试。浏览器使用隔离夹具，以下截图不代表学生真实数据、社区用户规模或教学质量分数；本轮无付费模型调用。
