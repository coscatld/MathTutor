Structured tutoring is driven by a state machine, not by a chat model deciding to reveal the answer.

## Student-visible loop

1. Submit a problem. Unsupported families become an unsupported state instead of a fake proof.
2. Attempt it independently.
3. Request a hint, explanation, or example. L0–L5 disclosure is clipped by `SolutionDisclosureProjector`.
4. Unsolved items require seeing a hint before the full answer.
5. A practice offer may follow. Released exercises pass the parse–solve–verify gate.

## Free chat

High-school paste-and-discuss can follow up and draw, but **free tutoring does not write independent-attempt mastery**. Viewing that item’s graph before answering counts as assisted.

## Graphs

Requests such as “draw y = x^2 - 2x - 3” compile through a whitelist parser. Coordinates are computed by the app. Model illustrations must call `draw_scene`.
