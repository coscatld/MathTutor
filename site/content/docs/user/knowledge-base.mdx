---
title: 知识库与参考资料
description: 保存学习资料、选择对话参考范围，并按引用追溯原文。
---

知识库保存讲义、题库与笔记，RAG 从当前允许使用的资料中检索相关内容，为回答提供参考。学习画像则记录学生的可核验作答；上传、阅读或收藏资料不会增加独立作答证据。

## 从资料到回答

1. **保存资料**：在知识库中创建资料库，导入文档或编辑 Markdown 笔记。文件夹、标签、版本与双向链接帮助整理内容。
2. **选择参考范围**：点击“选择当前对话资料”，或在辅导页打开“对话资料”。选择知识库、检查文档预览，再点击“应用到当前对话”。从知识库主入口进入时，可用“打开对话选择资料”开始新对话。
3. **查看引用**：回答引用资料时，打开引用查看对应版本、原文与可用的行号。引用说明内容来自哪里，不替代数学核验。

更改范围后，从下一条消息生效。打开选择器本身不会应用修改；关闭面板会在本次使用中保留草案。保存尚待确认时，应先“重新读取范围”，确认成功后继续对话。

## 两种文档范围

| 选择方式 | 实际使用范围 |
| --- | --- |
| 不勾选“仅使用我勾选的文档” | 当前对话上传的文档、已共享的总资料，以及所选知识库中允许检索的文档。向这些位置加入可检索资料，可能改变有效范围。 |
| 勾选“仅使用我勾选的文档” | 只使用明确勾选且当前可检索的文档；一份也不选时，不参考文本资料。 |

未选入对话的知识库不会仅因导入而被自动加入。停用的资料不参与检索；跨会话或跨用户的资料仍受服务端权限检查。面板显示的是后端确认的有效范围。

范围控制的是**文本检索**。已发送的图片由视觉模型读取，不受文档勾选列表控制。

## 资料问答与数学辅导

“问答方式与高级设置”中可选择数学辅导或资料问答。前者围绕题目分步讲解与练习，后者围绕所选资料回答。整理后的笔记可以预览，再决定保存到哪个知识库。

“用此库开始对话”会新建一个选择了该库的对话。需要控制到单份文档时，再到“对话资料”设置文档范围。

## 导入、检索与共享

支持共享题库 JSON、资料库 ZIP，以及文本、Markdown 和可提取文字的 PDF。Markdown 可编辑并保留历史版本，资料库可导出共享。课程参考答案与可核验练习分别标记；资料作者提供的答案不会自动成为数学验证结果。

默认使用词法检索。向量检索需在设置中显式下载或配置 Embedding，默认关闭；当前文档导入没有 OCR。扫描版 PDF 无可提取文字时，应先转换为文本，或把题目作为图片发送。

社区的资料、题库与代码插件分别导入。代码插件默认停用，需明确启用后按本机账户权限运行；资料导入不会运行插件。代码插件不是操作系统沙盒。
