## 对话资料

回答可以参考哪些资料，统一在“对话资料”里选择，先预览再应用。导入一份资料不会自动扩大当前会话范围。

## 知识库

按文件夹管理题库与 Markdown 笔记，支持编辑、版本、标签和双向链接。可导入共享题库 JSON / 资料库 ZIP，再导出当前正文。

题库规模以 README 为准：小学一年级至高三 383 个知识点、801 道原创课程题，另有支持本地步骤核验的练习与数形结合演示。课程参考题与可核验练习分开标记。作者 `answer` **不会自动变成形式化验证结果**。

## 检索

默认词法检索（FTS）。向量检索需在设置中显式下载或配置 embedding，默认关闭。支持文本、Markdown 和可提取文字的 PDF。没有 OCR。

## 社区

“发现资源”导入资料和题库；“我的插件”单独导入插件。代码插件默认停用，明确同意后按本机账户权限运行，**不是操作系统沙盒**。
