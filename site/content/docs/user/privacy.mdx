## 数据放在哪里

- 桌面版：操作系统用户数据目录（macOS 一般为 `~/Library/Application Support/MathTutor/`）。
- 源码后端：默认项目下 `data/`，可用 `MATHTUTOR_DATA_ROOT` 或 `MATHTUTOR_DB_PATH` 覆盖。
- API Key：系统钥匙串 / 凭据管理器，不进浏览器 `localStorage`。

## 什么会离开本机

使用外部模型服务时，**题目、上下文和相关资料片段会发送给你配置的服务商**。只用本地模板或本机 Ollama 时，数据不出本机。

社区源不接收学习记录。你在当前对话调用插件时，有界结果会提供给已配置的对话模型。

## 加密与备份

可选 SQLCipher 整库加密（默认关闭）。只要系统密钥存储可用，备份文件加密。请保存恢复密钥。卸载安装包默认保留用户数据。

## 图片

聊天图片以本机数据库 BLOB 保存。图片讨论不记作已验证作答。
