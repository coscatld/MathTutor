MathTutor is a desktop AI math learning and knowledge exploration app. Try a problem, use a hint if you need one, then try a related exercise. Your learning profile shows what you did independently and where you used help.

Supported calculations and problems can be checked locally. For other questions, the app explains which parts you can discuss. Online exploration brings in attributed excerpts and original links so you can read different explanations alongside each other.

Start with [installation](./installation.mdx) or the [exploration guide](./knowledge-exploration.mdx).
