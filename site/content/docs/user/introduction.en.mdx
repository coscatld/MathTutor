MathTutor is for students who need the process, not only the answer, and for parents, teachers, and developers who need sources, teaching behavior, and learning evidence.

It is an Electron shell, a Next.js workbench, and a Python product service. Runtime packaging no longer depends on the DeepTutor source tree. The project is still a DeepTutor-derived work under Apache-2.0, and it keeps the Data Intelligence Lab, The University of Hong Kong copyright notice.

## How it differs from generic AI chat

1. **Disclosure is a product boundary.** Low hint levels structurally cannot see the full verified solution.
2. **Math checks have a grammar.** Supported families are solved and verified locally. Out-of-scope reasoning is unlabeled.
3. **Evidence is split.** Independent, assisted, and after-reveal attempts are stored separately.
4. **Local-first.** Notes, sessions, and keys stay on the machine. Cloud models receive data only when you configure them.

## What this project does not claim

- No published user counts, star counts, or download marketing numbers.
- DKT experimental training is not a classroom learning-gain claim.
- Linux has no target-machine-verified public installer.
- There is no OCR. Vision depends on whether the current model reports vision.
