MathTutor 面向希望学会过程、而不只是拿到答案的学生，也面向需要检查资料来源、教学行为和学习依据的家长、教师与开发者。

它由 Electron 桌面壳、Next.js 工作台和 Python 产品服务组成。运行与打包不再依赖 DeepTutor 源码仓库，但项目是在 DeepTutor 上的二次开发，许可证仍为 Apache-2.0，并保留香港大学 Data Intelligence Lab 的版权声明。

## 和普通 AI 问答的区别

1. **答案披露是产品边界**：低提示等级的表达层在数据上看不到完整核验解。
2. **数学核验有范围**：受支持题型由本地求解器与验证器处理；超出语法的推理标为未核验。
3. **学习证据可分账**：独立、受助、看答案后的作答分开记录。
4. **本地优先**：资料、会话和密钥在本机；只有你配置了云端模型，请求才会离开本机。

## 当前不要期待的事

- 没有公开的用户量、Stars 或下载量宣传口径。
- 没有把 DKT 实验训练结果写成真实教学提升。
- Linux 没有经过目标机验证的公开发布包。
- 扫描图片没有 OCR；视觉能力取决于当前模型是否声明 vision。
