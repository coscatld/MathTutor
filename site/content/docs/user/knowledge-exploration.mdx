在原聊天中开启“联网”，就可以结合知乎来源解释概念、比较不同理解方式，或寻找学习资料。学习画像中的“下一步学习资料”则结合已有作答，帮助你选择起点和前置知识。

**当前通过源码体验。** 已发布的 macOS 和 Windows 安装包尚不包含知识探索。按[开发环境](../developer/development-setup.mdx)运行当前源码。这个官网提供使用说明，不运行知乎搜索或接收凭据。

## 在聊天中联网

1. 在应用的 `/math-tutor/settings?section=sources` 配置自己的知乎 Access Secret。也可在 Python 服务环境设置 `MATHTUTOR_ZHIHU_ACCESS_SECRET`；不要使用 `NEXT_PUBLIC_` 变量或把密钥写进仓库。
2. 回到原聊天，在输入框开启“联网”。例如问“分数为什么要通分”“可导和连续有什么关系”或“线性代数应该先学哪些概念”。
3. 追问一个例子、条件或下一步。相关的上一条联网问题会保留为上下文；关闭联网或新建会话后重新开始。
4. 查看回答中每段的来源、作者和原文入口。正在作答的数学题仍遵循原有核验与分级提示。

联网检索按公开知识主题发起，回答围绕你的实际问题组织。回答逐项接受自动来源支持检查；遇到无结果、超时、限流或证据不足时，会说明当前状态，并保留普通数学讨论入口。

## 看清解释和依据

| 回答内容 | 如何处理 |
|---|---|
| 资料解释 | 绑定接口摘要中的具体片段，保留适用条件 |
| 作者观点 | 与 AI 推导分开标记，不把摘要当作作者逐字原话 |
| 观点对照 | 至少关联两个来源，区分互补、条件不同与实际分歧 |
| 学习建议与推导 | 明确标记为 AI 推断，检查依据及前提依赖 |
| 数学表述 | 单独核验可解析的算式；自然语言推理仍需核对 |

应用保存来源快照、字符区间、摘要哈希和逐项检查记录。检查拒绝的结论及依赖它的后续结论会被省略，最终展示的解释不会再交给模型自由改写。

当前问题含有无歧义、受支持的计算式时，还可显示“MathTutor 本地核验”。它沿用本地求解器与验证器，保存原问题、算式区间和计算记录；标签只覆盖这里的计算，不能替整段解释背书。仅要提示或正在作答时，原有答案披露限制仍然有效。

知乎接口返回的是有数量和长度限制的检索摘要。自动语义检查仍可能误判；合法引用不等于数学证明，片段也不能代表全文或整个社区的观点分布。公式、上下文或限定条件缺失时，请回原文核对。

目前多轮条件对照和资料推荐仍可能遗漏问题要点或推荐理由，尚未通过完整问答质量验收。源码预览适合试用与反馈；学习结论请结合原文和自己的检查。

## 找到下一步学习资料

初始资料库有 **23 份经 AI 初审的可见片段**，覆盖分数、方程、线性代数、概率和微积分。每份保留标题、作者、原始链接、主题、推荐理由、审核范围和可获得的时间信息。平台的时间字段只标为“发布或更新”，未提供的初始发布日期保持未知。

这里的“已审片段”指对本次返回内容的限定范围初审，不表示人工专家审核或全文认证。打开“查看证据与审核范围”，可以直接看到依据。新检索结果单独标为“新发现 · 待阅读”。

学习建议复用已有作答记录和前置知识关系：需要时先看解释、完成检查或复习前置知识，再继续学习。阅读、看过答案和受助作答不会算成独立掌握；没有证据时会说明起点尚不清楚。微积分、机器学习等方向的建议也不会虚构这些领域的掌握度。

## 启动时后台发现

在“知识来源”设置中选择学习方向，开启“启动时在后台探索知乎资料”。外部后台探索默认关闭；本地资料与学习建议始终可用。

开启后，进入应用会异步检索，不等待搜索完成才展示工作台。相同学习状态复用六小时缓存，每位用户每日最多启动两次外部探索。重复启动会合并任务；网络失败或超时保留可用的本地资料。关闭设置后停止新的检索。

更换目标、排除作答证据或删除学习记录后，旧建议会失效。已取消任务的迟到结果不能重新写回旧内容；不同账户的资料、缓存和额度分别处理。

## 保存自己的理解

原有 `/math-tutor/explore` 阅读工作台保留问题、学习目标和思考记录。可选 AI 选择已登记片段与阅读重点，应用提供固定阅读问题。

目前提供 **16 道中英文固定理解检查题**。覆盖范围内可以根据真实作答和辅助状态选择最多三步的学习建议；其他主题保留开放问题。一次答对只说明这次作答，不代表长期掌握或迁移能力。

## 数据发送范围

| 操作 | 发给知乎的内容 |
|---|---|
| 原聊天联网 | 检索使用公开主题；直答使用当前问题、相关的上一条联网问题和来源片段 |
| 后台发现 | 公开知识主题，不发送作答详情、学习画像或私人资料 |
| 阅读工作台 | 主动搜索的问题；选择 AI 整理时还包括学习目标与已登记片段 |

密钥只由后端使用。桌面版通过系统凭据库保存，开发模式可能仅保存在内存中，设置页显示持久化状态。删除应用内保存的密钥后，服务器环境变量提供的密钥仍可能生效。

## 设计依据

来源归属、语义支持与数学正确性分别处理，参考 [ALCE](https://aclanthology.org/2023.emnlp-main.398/)、[RARR](https://aclanthology.org/2023.acl-long.910/) 和 [Sufficient Context](https://arxiv.org/abs/2411.06037)。学习路径复用现有证据与前置关系，参考 [KnowLP](https://arxiv.org/abs/2506.22303) 的问题设定；当前工程测试不代表已验证真实教学效果。
