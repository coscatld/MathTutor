知识探索把一次数学疑问串成“提出问题 → 对照来源 → 自己回答 → 选择下一步”。你可以保留学习目标，查看不同作者的解释，写下自己的理解，并完成一个小检查。

**当前为源码预览。** 已发布的 macOS 和 Windows 安装包尚不包含此功能。按[开发环境](../developer/development-setup.mdx)运行当前源码后，进入应用的 `/math-tutor/explore`。这个官网提供使用说明，不运行知乎搜索，也不接收凭据。

## 开始探索

1. 在应用的 `/math-tutor/settings?section=sources` 配置自己的知乎 Access Secret。也可在启动 Python 服务的环境中设置 `MATHTUTOR_ZHIHU_ACCESS_SECRET`；不要使用 `NEXT_PUBLIC_` 变量或把密钥写进仓库。
2. 打开 `/math-tutor/explore`，输入问题与学习目标，再主动发起搜索。例如，可以探索“为什么除以一个式子前要检查它是否为零”。
3. 阅读来源卡片，查看作者、标题、检索片段和原始链接。片段有缺口或缺少公式时，回原文核对。

搜索由后端调用知乎接口。凭据不写入浏览器存储、应用数据库或代码仓库；桌面应用通过系统凭据库保存。开发模式可能只在内存中保存，设置页会显示是否能持久保存。删除应用内保存的凭据后，如果服务器仍配置环境变量，该环境凭据会继续生效。

## 对照解释

搜索本身不需要 AI 整理。可选 AI 只选择已登记片段与阅读重点（定义、条件、推理或例子），应用据此生成固定阅读问题。比较也使用固定问题。原文与链接来自保存的来源，AI 不能另造引文、替换链接或发布自由生成的事实判断。

比较项是**待核对的阅读线索**。它不会认证两个说法相互矛盾、完全等价，或证明某位作者的数学结论正确。可以先比较适用条件、符号含义与推理步骤，再回到原文判断差异。

## 留下自己的理解

写下你的解释、仍有疑问的条件或准备尝试的例子，保存为本次探索的思考记录。原问题、目标和记录一起保留，方便之后继续。

目前内置 **16 道中英文理解检查题**，覆盖有限的数学概念。可用时，检查题会提供一个具体问题，并根据实际作答与辅助状态给出最多三步的学习建议。未覆盖的主题保留开放问题，不生成未经核验的判分题。

阅读、保存思考、看过解释和独立作答分别记录。答对一道题只能说明这次作答；它不会自动写成掌握度，也不能证明知识已迁移到新情境。

## 来源能说明什么

| 看到的内容 | 可以确认 | 仍需判断 |
|---|---|---|
| 原文片段 | 对应这次检索保存的文本与字符区间 | 片段之外的全文、公式或上下文 |
| 作者与原始链接 | 来源归属与回看入口 | 作者说法是否准确、是否适用于你的问题 |
| 阅读问题与比较建议 | AI 选择已登记片段，应用提供固定问题 | 语义支持、等价、矛盾或数学真值 |
| 理解检查反馈 | 这道固定题的作答与辅助状态 | 长期掌握、教学效果与迁移能力 |

知乎接口返回的是有数量和长度限制的检索摘要，不是完整文章，也不代表整个社区的观点分布。相同内容的重复返回不会被当作多份独立支持。缺少来源时，页面保留缺口，不补造证据。

## 数据发送范围

主动搜索会把问题发送给知乎。选择 AI 整理时，问题、学习目标和已登记的来源片段会交给知乎直答服务。思考记录和检查作答保存在本地应用中；不要在检索问题中放入不希望发给外部服务的个人信息。

## 设计依据

来源归属与支持判断参考 [AIS](https://aclanthology.org/2023.cl-4.2/)、[ALCE](https://aclanthology.org/2023.emnlp-main.398/) 和 [Attribute First](https://aclanthology.org/2024.acl-long.182/) 的研究。这里的来源绑定用于检查引文完整性；语义忠实性与真实学习效果需要单独评价。
