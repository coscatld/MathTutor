---
title: 学习画像与证据
description: 查看实际作答、区分帮助条件，并用新题继续验证。
---

学习画像回答三个问题：已经做过什么、当时得到过哪些帮助、接下来还需要验证什么。它以服务端记录的作答事实为依据，不把知识库的资料量、聊天次数或模型预测展示为掌握率。

## 先看下一步，再看依据

画像首屏给出下一步入口和“已观察的技能”数量。这个数量表示作答记录覆盖了哪些技能，**不是掌握比例**。下方每条观察分别展示独立、受助与答案后的答对次数；“证据计数”可展开查看答错与诊断记录。

点击“查看依据”，可以查看原题、自己的作答、核验结果、时间与帮助条件；原会话仍可用时，也可回到原题。没有作答证据时，页面引导先完成一道可核验的题目。

## 记录如何区分

| 记录类型 | 含义与使用边界 |
| --- | --- |
| 独立作答 | 新题首次作答，未使用提示或本题图像帮助，整题自由作答有明确对错、帮助来源明确，且此前没有暴露目标答案；诊断与错误分析任务不计入。 |
| 受助作答 | 使用过提示、解释、例题或相关图像帮助后的表现。可以记录进展，但不合并为独立成功。 |
| 答案后作答 | 在目标答案或完整解答已展示后作答。需要换题观察独立表现。 |
| 诊断与步骤记录 | 选择题初评、诊断任务、错误分析、单个步骤或部分完成。用于了解起点与困难，不作为首次独立整题成功。 |
| 待确认 | 无法核验，或帮助来源不明确。保留可用记录，但不计为独立正确。 |

同题重复作答不会产生另一条“新题首次独立”证据。涉及多个技能的整题结果作为联合证据处理，不直接拆成每个技能各自掌握。看过资料、收藏题目、说“懂了”以及自己填写的目标，都不构成独立成功。

## 纠正记录与阶段复盘

发现判定有问题时，在依据中选择“这条记录有问题”，确认后“排除这次判定”。系统根据有效记录重新计算画像，原作答顺序仍保留；排除首次判定不会让同题重做变成首次作答。

“阶段学习复盘”整理已验证记录的变化和下一步观察建议。“学习目标与讲解偏好”按需展开；这些自选信息帮助安排学习，不会成为能力判断的依据。复盘在读取、排队和失败时分别显示相应状态。

## 模型预测与学习效果

产品画像使用证据投影 `evidence_tracker_v2`。DKT 是独立预测管道，在满足适用条件时辅助教学策略；其预测不会直接变成画像中的独立成功或长期掌握证明。

一次答对、提示后完成或普通代码测试通过，都不能证明长期学习效果。需要在不同题目、迁移情境或延迟复习中继续收集作答证据；产品效果仍需专门评测。
