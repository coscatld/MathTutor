## Windows

1. Download the EXE and check `SHA256SUMS-0.7.0-win-r2.txt`.
2. Run the installer. SmartScreen may appear because the file is not Authenticode-signed.
3. You do not install Python or Node separately.

## macOS

The original Mac build was withdrawn for incomplete resource signatures. Use r2. r2 is fully ad-hoc signed locally, **without Developer ID and without notarization**. Gatekeeper rejects it by default.

Follow [docs/MACOS_INSTALLATION.md](https://github.com/coscatld/MathTutor/blob/main/docs/MACOS_INSTALLATION.md): verify SHA-256, drag the app into Applications, and allow it under Privacy & Security if asked.
