Current release **0.7.1**, with recent fixes for graph interaction, draft protection, learning evidence, retrieval, and local services.

| OS | File |
|---|---|
| Windows 10/11 x64 | `MathTutor-0.7.1-win-x64.exe` |
| macOS Apple Silicon | `MathTutor-0.7.1-mac-arm64.dmg` |

Release page: [v0.7.1 Releases](https://github.com/coscatld/MathTutor/releases/tag/v0.7.1). Checksums and platform acceptance records accompany the release assets.

Before upgrading, create and verify an in-app backup, quit the old version, then install the update. The database migration head remains **024**, with no new schema migration in this release. Save community and plugin settings separately.

## Windows

1. Download the Windows EXE installer.
2. Run the installer. SmartScreen may appear because the file is not Authenticode-signed.
3. You do not install Python or Node separately.

## macOS

0.7.1 is fully ad-hoc signed locally, **without Developer ID and without notarization**. Gatekeeper rejects it by default. Check the file source and checksum before explicitly allowing it to open.

Follow [docs/MACOS_INSTALLATION.md](https://github.com/coscatld/MathTutor/blob/main/docs/MACOS_INSTALLATION.md): drag the app into Applications, and allow it under Privacy & Security if asked.

## Linux
