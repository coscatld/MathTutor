Before upgrading, create and verify an in-app backup, quit the old version, then install the update. The app migrates its local database as needed. Save community and plugin settings separately.

## Windows

1. Download the Windows EXE installer.
2. Run the installer. SmartScreen may appear because the file is not Authenticode-signed.
3. You do not install Python or Node separately.

## macOS

The current installer is fully ad-hoc signed locally, **without Developer ID and without notarization**. Gatekeeper rejects it by default. Check the file source and checksum before explicitly allowing it to open.

Follow [docs/MACOS_INSTALLATION.md](https://github.com/coscatld/MathTutor/blob/main/docs/MACOS_INSTALLATION.md): drag the app into Applications, and allow it under Privacy & Security if asked.
