Current release **0.7.0**. Use the r3 installers.

| OS | File |
|---|---|
| Windows 10/11 x64 | `MathTutor-0.7.0-win-x64-r3.exe` |
| macOS Apple Silicon | `MathTutor-0.7.0-mac-arm64-r3.dmg` |

Release page: [v0.7.0 Releases](https://github.com/coscatld/MathTutor/releases/tag/v0.7.0)

## Windows

1. Download the Windows EXE installer.
2. Run the installer. SmartScreen may appear because the file is not Authenticode-signed.
3. You do not install Python or Node separately.

## macOS

The original Mac build was withdrawn for incomplete resource signatures. Use r3. r3 is fully ad-hoc signed locally, **without Developer ID and without notarization**. Gatekeeper rejects it by default.

Follow [docs/MACOS_INSTALLATION.md](https://github.com/coscatld/MathTutor/blob/main/docs/MACOS_INSTALLATION.md): drag the app into Applications, and allow it under Privacy & Security if asked.

## Linux
