| Platform | Download | Install |
| --- | --- | --- |
| macOS · Apple Silicon | [MathTutor DMG](https://github.com/coscatld/MathTutor/releases/download/desktop-20261118/MathTutor-mac-arm64.dmg) | Open the disk image, drag MathTutor into Applications, then open it there. |
| Windows 10/11 · x64 | [MathTutor EXE](https://github.com/coscatld/MathTutor/releases/download/desktop-20261118/MathTutor-windows-x64.exe) | Open the installer, follow the wizard, then launch MathTutor from Start. |

## First launch

The Mac app has an ad-hoc signature and has not been notarized by Apple. The Windows installer has no publisher certificate. If your system prompts you, check the filename, platform and SHA-256 checksum on the [official release page](https://github.com/coscatld/MathTutor/releases/tag/desktop-20261118). On macOS you can allow this app under System Settings → Privacy & Security.

## Updating

Create and verify an in-app backup, quit MathTutor, then install the new package. Open the app and check your learning records and materials. Continue with [your first exercise](./quick-start.mdx).
