## Conversation sources

What an answer may read is chosen in “对话资料”, previewed, then applied. Importing a file does not silently widen the current session.

## Library

Folders hold question packs and Markdown notes, with editing, versions, tags, and backlinks. Shared pack JSON / library ZIP files can be imported and re-exported.

Question-bank counts follow the README: 383 knowledge points from grade 1 to 12, 801 original course items, plus locally verifiable practice and graph demos. Course keys and verifiable practice are labeled separately. An author `answer` **does not become a formal verification**.

## Retrieval

Lexical FTS is the default. Vector search is an explicit embedding opt-in and is off by default. Text, Markdown, and text-extractable PDFs are supported. There is no OCR.

## Community

“发现资源” imports notes and packs. “我的插件” imports plugins separately. Code plugins stay disabled until you consent. They run with your OS user rights and **are not an OS sandbox**.
