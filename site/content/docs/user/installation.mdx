| 系统 | 下载 | 安装 |
| --- | --- | --- |
| macOS · Apple Silicon | [MathTutor DMG](https://github.com/coscatld/MathTutor/releases/download/desktop-20261125/MathTutor-mac-arm64.dmg) | 打开磁盘映像，将 MathTutor 拖入“应用程序”，从那里启动。 |
| Windows 10/11 · x64 | [MathTutor EXE](https://github.com/coscatld/MathTutor/releases/download/desktop-20261125/MathTutor-windows-x64.exe) | 双击文件，跟随安装向导，从开始菜单打开 MathTutor。 |

## 首次打开

macOS 包使用本地签名，未经过 Apple 公证。Windows 包没有发行者证书。若系统提示来源未知，请先在[官方发布页](https://github.com/coscatld/MathTutor/releases/tag/desktop-20261125)核对文件名、平台和 SHA-256 摘要。在 Mac 上可通过“系统设置 → 隐私与安全性”允许本次打开。

## 升级

在应用中创建并验证备份，退出 MathTutor，再安装新包。打开后可以在设置中检查原来的学习记录和资料。接下来试试[第一道练习](./quick-start.mdx)。
