当前正式版本 **0.7.0**。请使用 r3 安装包。

| 系统 | 文件 |
|---|---|
| Windows 10/11 x64 | `MathTutor-0.7.0-win-x64-r3.exe` |
| macOS Apple Silicon | `MathTutor-0.7.0-mac-arm64-r3.dmg` |

发布页：[v0.7.0 Releases](https://github.com/coscatld/MathTutor/releases/tag/v0.7.0)

## Windows

1. 下载 Windows EXE 安装包。
2. 按安装向导安装。出现 SmartScreen 时，这是因为安装包没有 Authenticode 发行证书签名。
3. 不必另装 Python 或 Node。

## macOS

原始 Mac 包因资源签名不完整已撤回，请改用 r3。r3 是完整本地 ad-hoc 签名，**没有 Developer ID、未公证**，Gatekeeper 默认拒绝。

步骤见仓库 [docs/MACOS_INSTALLATION.md](https://github.com/coscatld/MathTutor/blob/main/docs/MACOS_INSTALLATION.md)：把应用拖入“应用程序”，必要时在“隐私与安全性”中允许。

## Linux

仓库配置了 AppImage 目标，但发布矩阵将 Linux 标为 **UNTESTED — NO TARGET MACHINE**，本页不提供下载入口。
