当前正式版本 **0.7.1**，包含近期图形交互、草稿保护、学习证据、资料检索和本地服务修复。

| 系统 | 文件 |
|---|---|
| Windows 10/11 x64 | `MathTutor-0.7.1-win-x64.exe` |
| macOS Apple Silicon | `MathTutor-0.7.1-mac-arm64.dmg` |

发布页：[v0.7.1 Releases](https://github.com/coscatld/MathTutor/releases/tag/v0.7.1)。文件摘要和分平台验收记录随发布资产提供。

升级前创建并验证应用内备份，正常退出旧版，再安装新版。数据库 migration head 保持 **024**，本版未新增结构迁移；社区与插件配置需要单独保存。

## Windows

1. 下载 Windows EXE 安装包。
2. 按安装向导安装。出现 SmartScreen 时，这是因为安装包没有 Authenticode 发行证书签名。
3. 不必另装 Python 或 Node。

## macOS

0.7.1 使用完整本地 ad-hoc 签名，**没有 Developer ID、未公证**，Gatekeeper 默认拒绝。请先核对文件来源与摘要，再明确允许打开。

步骤见仓库 [docs/MACOS_INSTALLATION.md](https://github.com/coscatld/MathTutor/blob/main/docs/MACOS_INSTALLATION.md)：把应用拖入“应用程序”，必要时在“隐私与安全性”中允许。

## Linux

仓库配置了 AppImage 目标，但发布矩阵将 Linux 标为 **UNTESTED — NO TARGET MACHINE**，本页不提供下载入口。
