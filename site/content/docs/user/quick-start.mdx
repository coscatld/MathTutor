---
title: 快速开始
description: 从第一次独立作答到换题检验。
---

1. [安装](./installation.mdx)并打开 MathTutor。初次配置模型和入门测评都可以跳过。语言可在设置中切换。
2. 在新对话中输入 `2x + 3 = 7`。先试着写出自己的第一步。
3. 卡住时点“提示”，根据引导再试一次。看过提示后仍有疑问，可以查看解答。
4. 完成后接受一道相关练习，再打开学习画像，查看两次作答分别用了多少帮助。

本地基础练习可以离线完成。要查找外部解释，在“设置 → 知识来源”连接知乎，在聊天中开启“联网”。例如问「分数相加为什么要通分？」。 [知识探索](./knowledge-exploration.mdx)
