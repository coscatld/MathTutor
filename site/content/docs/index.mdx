MathTutor（数迹）是基于学习过程追踪与可验证解题的开源数学智能辅导系统。当前正式版本是 **0.7.0**。

## 先读这里

- 学生与使用者从 [简介](user/introduction) 和 [安装](user/installation) 开始。
- 开发者从 [架构概览](developer/architecture) 和 [开发环境](developer/development-setup) 开始。
- 下载入口见官网 [Download](https://github.com/coscatld/MathTutor/releases/tag/v0.7.0) 或 [GitHub Releases](https://github.com/coscatld/MathTutor/releases/tag/v0.7.0)。

## 阅读约定

| 标记 | 含义 |
|---|---|
| 已实现 | 仓库有对应代码，并有测试或发布说明 |
| 部分实现 | 主路径可用，但有明确限制 |
| 实验性 | 可运行，但不能当成真实教学效果 |
| 规划中 | 路线图，尚未作为产品能力宣传 |

DKT 的 ASSISTments 训练与合成评估不是 MathTutor 课堂效果。评测分数只对应文档里写明的样本与版本。
