## 先分清三个地方

**数学对话：完成一次学习。** 提交题目和自己的尝试，需要时获取提示，再用新题检验理解。见[教学流程](user/tutoring-workflow)。

**知识库：整理回答的参考资料。** 保存讲义、笔记和题库；在对话的“对话资料”中选择本轮参考范围，再从回答的引用查看原文。导入资料不等于已经学会其中的知识。

**学习画像：查看实际作答留下的证据。** 独立完成、提示后完成和看答案后的作答分开记录，结合记录选择下一次练习。模型预测与自我报告不能替代独立验证。

## 开发者阅读路线

先[运行项目](developer/development-setup)，再按模块查阅：

- [架构概览](developer/architecture)：前端、桌面壳和 Python 服务的边界。
- [教学状态机](developer/teaching-state-machine)与[数学求解](developer/math-solver)：教学和验证如何衔接。
- [检索与 RAG](developer/retrieval-rag)：资料范围、检索和引用追踪。
- [学习证据与 DKT](developer/evidence-dkt)：事实、投影和预测的区别。
- [测试与评测](developer/testing-evaluation)：如何验证代码、检索和教学行为。

## 版本与验证范围

公开安装包为 **0.7.0 r3**；本地源码改进需经后续发布才能进入安装包。安装方式见[安装指南](user/installation)。

文档中的“已实现”表示仓库存在对应能力；“部分实现”和“实验性”会列明适用范围。工程测试、固定样本评测和真实学生学习效果分别验收。DKT 训练与合成评估不代表 MathTutor 的课堂效果。
