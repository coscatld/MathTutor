description: Electron packaging entry points, the platform matrix, and signing status.
---

Desktop code lives in `desktop/`. Do not change `main.js` startup to ship the website.

Existing scripts (names as in the repo):

- macOS: `npm --prefix desktop run package:mac:unsigned` and `desktop/scripts/verify-macos-dmg.cjs`
- Windows: `desktop/scripts/build-windows.ps1`, `run-windows-release-smoke.ps1`
- Workflows: `.github/workflows/release-packaging.yml`, `windows-installer.yml`

`docs/rc/PLATFORM_RELEASE_MATRIX.md`: macOS arm64 and Windows x64 build/package/launch are PASS; signing is PARTIAL. Linux is UNTESTED.

Public artifacts: Windows x64 NSIS r3 and macOS arm64 DMG r3. Neither uses a release certificate; macOS is not notarized.
