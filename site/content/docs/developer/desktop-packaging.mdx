桌面工程在 `desktop/`。不要修改 `main.js` 启动逻辑来适配官网。

已有脚本（名称以仓库为准）：

- macOS：`npm --prefix desktop run package:mac:unsigned` 及 `desktop/scripts/verify-macos-dmg.cjs`
- Windows：`desktop/scripts/build-windows.ps1`、`run-windows-release-smoke.ps1`
- 工作流：`.github/workflows/release-packaging.yml`、`windows-installer.yml`

`docs/rc/PLATFORM_RELEASE_MATRIX.md`：macOS arm64 与 Windows x64 的构建/打包/启动为 PASS，签名为 PARTIAL。Linux 为 UNTESTED。

当前版本 0.7.1 提供 Windows x64 NSIS 与 macOS arm64 DMG。两者均无发行证书签名；Mac 使用完整本地 ad-hoc 签名，未公证。具体构建来源与安装验收以 [0.7.1 发布记录](https://github.com/coscatld/MathTutor/releases/tag/v0.7.1) 为准。
