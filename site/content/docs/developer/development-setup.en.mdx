## Requirements

- Python 3.12 recommended; declared `>=3.11,<3.14`
- Node.js 24, matching current source CI
- Use lockfiles and `npm ci`

## Install

```bash
python -m pip install -e ".[dev]"
cd web && npm ci
cd ../desktop && npm ci
```

Optional extras: `.[embedding]`, `.[pdf-rich]`.

## Run the workbench

Start the backend from the repository root after installing Python dependencies:

```bash
python -m mathtutor
```

Start the frontend in another terminal:

```bash
cd web
npm run dev
```

Open `http://127.0.0.1:3000` in the browser. Use the repository's `npm run dev` entry point; it configures the environment and origin checks for local browser development.

Public reference search works without a key. Knowledge exploration is at `/math-tutor/explore`. To enable the optional Zhihu source, configure the Zhihu Access Secret at `/math-tutor/settings?section=sources`, or set the server-only environment variable `MATHTUTOR_ZHIHU_ACCESS_SECRET` before starting Python. See [Knowledge exploration](../user/knowledge-exploration.mdx) for the workflow.

## Existing checks

```bash
python scripts/check.py
python -m pytest tests/test_community_plugins.py tests/test_community_plugins_api.py tests/test_code_plugins.py -q
cd web && npm run test && npm run build
```

## Run the documentation website

The website and workbench are separate projects. From the repository root:

```bash
cd site
npm ci
npm run dev   # http://127.0.0.1:3000/MathTutor/
```

The website exports statically to GitHub Pages. It does not run Python or store API credentials. Validate the export with `npm run build` and `npm run verify:export`.
