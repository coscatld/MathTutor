## 要求

- Python 建议 3.12，声明 `>=3.11,<3.14`
- Node.js 24，与当前源码 CI 保持一致
- 使用仓库锁文件和 `npm ci`

## 安装

```bash
python -m pip install -e ".[dev]"
cd web && npm ci
cd ../desktop && npm ci
```

可选：`.[embedding]`、`.[pdf-rich]`。

## 运行工作台

在已安装 Python 依赖的项目根目录启动后端：

```bash
python -m mathtutor
```

另开终端启动前端：

```bash
cd web
npm run dev
```

浏览器打开 `http://127.0.0.1:3000`。使用仓库的 `npm run dev` 入口，它会配置本机浏览器开发所需的环境与来源检查。

公开百科和教材检索免密钥。知识探索入口为 `/math-tutor/explore`。在 `/math-tutor/settings?section=sources` 可选配置知乎 Access Secret，或在启动 Python 服务前设置服务端环境变量 `MATHTUTOR_ZHIHU_ACCESS_SECRET`。完整流程见[知识探索](../user/knowledge-exploration.mdx)。

## 检查命令（仓库已有）

```bash
python scripts/check.py
python -m pytest tests/test_community_plugins.py tests/test_community_plugins_api.py tests/test_code_plugins.py -q
cd web && npm run test && npm run build
```

## 运行文档网站

官网与工作台是两个独立项目。在项目根目录执行：

```bash
cd site
npm ci
npm run dev   # http://127.0.0.1:3000/MathTutor/
```

官网静态导出到 GitHub Pages，不运行 Python 服务或保存 API 凭据。验证导出使用 `npm run build` 与 `npm run verify:export`。
