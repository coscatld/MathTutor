## Status labels

| Label | Meaning |
|---|---|
| Implemented | Code exists, with tests or release notes |
| Partial | The main path works, with documented limits |
| Experimental | Runnable, not a classroom-effect claim |
| Planned | Roadmap only |

DKT training on ASSISTments and synthetic evaluations is not a MathTutor classroom outcome. Benchmark numbers apply only to the sample and version named in the source report.
