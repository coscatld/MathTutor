# 资料界限与文件结构

| 文件 / 字段 | 被测智能体可见 | 用途 |
|---|---|---|
| `public/*: prompt` | 是 | 原任务说明、题干、截止当前学生轮次的历史；包括上游固定 few-shot 示例。 |
| `public/*: grade` | 是，作为产品学习阶段设置 | 本轮适配设置，不是人工逐题年级标签。 |
| `public/*: id/source/task/group/split` | ID 用于会话标识，不进入语言提示 | 追踪样本、题组、版本和分割，不可作为答案检索键。 |
| `private/gold.json: answer` | 否 | 源参考解答或数值答案；只供评分。 |
| `private/gold.json: error_step/is_error` | 否 | 原始错误定位及分类标签；不改成模型的答案。 |
| `private/gold.json: teacher_gold` | 否 | 隐藏的教师下一轮回应；只用于分析。 |
| `private/gold.json: rubrics` | 否 | TutorBench 逐题标准；只给独立评审器。 |
| `private/judge_calibration.json` | 否 | 原数据的人类标签及对应回答；与所有被测问题分组隔离。 |
| `results/*/{dev,test}/<id>.json: text` | 真实产品返回 | 产品返回的内容载荷，包含应用验证通知、自动追加内容及画布块；界面会把画布块渲染为图形。本轮评审读取文本载荷，不实际操作图形。 |
| 同文件 `trace` | 评测记录 | 被测提供商调用的输入消息、可见输出、模型、token、完成原因；不保存密钥或隐藏思维内容。 |
| `review/*/blind_mapping.json` | 不给评审器 | 匿名 ID 与版本对应关系；评审提示中没有基线/候选身份。 |
| `review/*/*.prompt.txt / *.raw.json` | 独立评审调用 | 原始输入及原始 CLI 结果，支持复核，不回传被测智能体。 |
| `review/*/*.normalized.json` | 派生评分记录 | 仅做编号转换或有记录的结构修复；保留原始结果。 |
| `exclusions.json` | 不影响题目生成 | 最终评分前根据近重复输入隔离一题，主要分析 311 条；原 312 条保留。 |

MathTutor 的教学、验证、路由和绘图策略在固定源快照中。每题只通过公开产品 WebSocket 发一次 `send_message`；不为低分题添加提示、改写问题或申请第二次完整答案。产品自身的工具调用、核验重写或自动续写按原有预算运行，完整留在记录中。

第 3 轮候选中的算术预检查（最终未采用）只读取当前可见数学式，逐对检查等号相邻的纯数值四则运算；最多 12 对、每侧最多 120 字符。含变量、未知 LaTeX、指数或其他复杂表达式不在预检查范围。它只传递确定的局部矛盾给教师，不证明整个解答正确、不推断学习掌握、不产生学习成绩。

模型接触公开基准的预训练历史不可排除。评审器看到参考答案和 rubric 是评分权限，不等于学生或被测智能体也能看到它们。
