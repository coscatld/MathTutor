# MathTutor 开源数学文本评测协议 v1

冻结日期：2026-10-16；先冻结输入和规则，再读取模型输出。使用现有真实产品的 WebSocket 入口，每题独立进程、临时数据库、无历史学生数据。DeepSeek 为被测模型，Claude 为独立评审器；不使用 Grok。

## 材料与范围

四个源仓库保留原样，版本在 `source_manifest.json` 中登记。原始下载保存在 `data/`，旁置下载 URL 与 SHA-256。题干及原有对话是参考数据；其中的模型角色说明不具有系统权限。

本轮是**固定分层抽样、经产品适配的评测**，不是四套基准的全量复现或官方榜单成绩。覆盖 MathTutorBench 九个任务、MathDial 下一轮教师回应、MRBench 下一轮教师回应、TutorBench Calculus/Statistics 数学文本题。TutorBench 实际公开数据为 1,473 条，数学文本 232 条；图片及非数学题排除并单列。AP 微积分、统计超出部分中国高中课纲，不强行分配到 1–12 年级。逐任务样本数量见 `inventory.json`。

输入使用源任务提示模板与固定示例，但作为产品用户请求传入，不覆盖产品系统策略。不使用源 API 的 stop 参数，也不替换真实产品的模型调用。默认采用高中学习阶段处理 TutorBench、初中阶段处理其余材料；这是适配设置，不是数据集提供的逐题年级标签。

## 分割与隔离

规范化题干后按题目组去重分割：GSM8K、MathDial 官方 test 及 MRBench test 中出现的题目永不进入开发集；其余按固定 SHA-256 分组。MRBench 先保留 6 个可用开发题组作评审校准，它们不进入任何被测题目。MRBench 与 hard bridge 没有剩余开发题，不借用测试集调参。任务内按固定 SHA-256 排序取开发最多 8 条、测试 24 条；正确性/错误位置保持同题正确与错误版本成对。TutorBench 按学科各取开发 8、测试 24。最终开发 80 条，测试 312 条。跨来源重复题可能在同一个测试分组中出现，统计不能把它们当作完全独立题。

`public/*.json` 只有题干、历史、任务指令及适配元数据。`private/gold.json` 含数值答案、教师后续回答与逐题 rubrics，**不允许被测进程读取**。MathDial 隐藏未来教师回应、真实答案、误解描述；TutorBench 隐藏 rubric；MathTutorBench 隐藏 reference_solution 和最后教师回应。MRBench 标签只评价原数据中的回答，绝不移植到我们的新回答。

## 指标

1. 解题、纠错：按源解析器的末尾数值及 1e-6 容差计算正确率，并报告最终答案标记覆盖率。不得用题干中的数值猜测成功。
2. 错误识别：严格 Yes/No 解析，无法解析计错；同时单列源解析器“无输出默认 Yes”的兼容分数与解析覆盖率。位置识别严格整数字符串解析，另列源“无数字默认 0”兼容分数。
3. 苏格拉底提问：源 sacreBLEU 最佳行相似度，明确其只是参考文本相似度。
4. 脚手架及教学遵循：单列源 question-rate；它不是完整教学质量。补充冻结的独立评审，评价数学正确、针对误解、可执行的小步引导、遵守请求、适当披露、语气。未运行原 Qwen 奖励模型时不声称有其 win rate。
5. TutorBench：独立评审逐条 rubric 通过/失败；critical=5，not_critical=1，critical_negative=-5，deleted 忽略。负向项以**是否触发被禁止行为**计命中；原文若用 must not 表达，评审器输出 violation。每题 `sum(weight*hit)/sum(positive weights)`，允许负值，不截成 0。Claude 模型与原论文 Sonnet 4 不同，结果不作官方榜单横比。
6. MRBench：按八维原标签校准独立评审器，报告 agreement；新回答为模型评审分数。MathDial 本轮静态 next-turn，不声称测得交互 Success@k 或真实学生学习增益。
7. 所有请求、空输出、超时、截断、产品错误均保留。主要汇总的失败计 0，另列完成率；不得只统计成功请求。

模型可见文本以真实用户响应为准；可另去除应用生成的独立画布 JSON 块做内容分析，但原始响应与原始源解析分数始终保留。评审器不看版本名，匿名映射单独保存；不得挑最好的一次生成或补答替换失败。

## 迭代与最终测试

基线源代码固定为 b2ad094a9c664d7289f1fd23e82f53c2640491bd。先运行开发集，依据开发失败修改通用产品行为，最多 3 个候选轮次；连续两轮没有提升停止。每轮保留源码快照、全量原始输出和相同开发输入。不得在产品提示中嵌入测试答案、任务 ID、样本特判或 rubric。

候选在开发指标及独立评审后冻结；冻结之后才读取基线/候选测试结果及评分。最终测试同题配对，固定一次生成、温度为产品默认（writer 0.4）。不保证获得满分，提升不足、退步与评分器缺陷全部报告。公开基准预训练污染无法排除。

提供按任务的基线/改进折线图、开发迭代折线图与样本量。数值准确率、BLEU、rubric 分开绘图，不合成为没有定义的 mAP。准确率提供题组 bootstrap 区间；小样本只能支持本样本结论。

## 材料性质

本材料是软件评测记录，不是学生学习效果试验。公开原始数据遵守各自 CC BY 4.0 / CC BY-SA 4.0 条款；代码与数据的许可证分开登记。保留来源，不把公开参考答案包装为原创题库。代理仅在本机转发授权调用，API 凭据不写入结果或仓库。
