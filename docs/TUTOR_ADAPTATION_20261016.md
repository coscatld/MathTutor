# 学生模型与回答质量改进（2026-10-16）

本轮修改教学与生成链路。沿用随包 ASSISTments 2009 DKT 权重，没有重新训练或扩大来源技能映射；此前保存的四基准回答、评分和图表保持原样，没有调用付费模型。

## DKT 如何影响实际输出

普通聊天先识别当前有明确依据的知识点，读取当前用户的可信学习事件，再用本地权重生成预测。每轮只读取一次快照，数学纠错时复用；这不改写呈现题目时保存的冻结预测，也不写入新的掌握证据。

| 条件 | 生成模型收到的教学要求 |
| --- | --- |
| 当前映射技能的 DKT 概率低于 0.45，且该技能至少两道首次独立整题作答错误 | 将该操作拆小一档，解释本步依据和检查方法 |
| 当前映射技能的概率高于 0.75，且至少三道独立正确、最近三道均正确、独立正确占比至少 75% | 少重复一档已证实基础操作的解释，把篇幅留给当前疑点 |
| 无同技能证据、模型缺失、映射不支持、概率非法或模型与证据不一致 | 保持中性，不凭空给学生贴标签 |

上表阈值是教学策略规则，沿用原有 0.45/0.75 分界，不是经过本轮实验选出的最优阈值。支持度由真实题目计数说明，不称为校准置信度。

指令明确列出所依据的基础知识点及其正确/错误记录数，不把代数预测泛化为整道高中综合题的能力。学生当前困惑优先；要求完整解析时仍完整回答，要求提示时不提前揭示答案，语言和长度等要求继续生效。

结构化教学继续使用呈现时的冻结预测，在当前教学目标确实有本人独立作答记录时调节最多一级。模型指导与已验证的错误指导合并，不再被已有指导文本覆盖；高概率不能撤回正在请求的提示、解释、示例，也不能覆盖当前错误或反复卡住的证据。旧冻结记录缺少新目标证据字段时安全降级，原记录不重写。

受助、看答案、重复尝试、失效事实、诊断、未知判定及不可靠来源不能当作首次独立整题成功。联合技能整题结果可以进入既有 DKT 编码，但不在聊天策略中复制成各知识点的独立掌握证据。所有读取按用户隔离；讲解、自述“懂了”和模型自己的答案不增加独立证据。

当前技能图和来源映射主要覆盖基础代数，不能据此生成导数、圆锥曲线或统计推断的掌握率。`MATHTUTOR_DKT_TEACHING=off` 可关闭 DKT 教学调节。逐轮诊断记录教学策略、证据数、知识点、原因和模型哈希，便于检查模型是否真正参与，且不保存原始学生回答到这些诊断字段中。

## 同时修复的回答问题

- 区分当前学生请求、题目和历史教师发言；“只提示”不被旧对话中的索答覆盖，禁用导数或禁止舍入不被误读为禁止答案。
- 将明确的句数、提问数、语言和短格式要求放到默认风格之后。违规只如实记录，不截断证明、不替模型选择 Yes/No，也不改历史评分。
- 常规核验范围通过独立公共字段在真实界面正文后展示，实时、回放、重启和崩溃恢复均保留；错误算式的醒目标记仍在正文。
- 数学修复继续遵守原请求的语言、提示范围与首次贴题边界，不把内部中文纠错消息当成新学生问题。
- `verify_math` 新增 `derivative(多项式,x)`，使用精确有理系数核对最高 12 次一元多项式导数；链式法则漏乘、幂次和符号错误能返回 `refuted`。变量分母、一般函数、参数及资源超限仍为 `unchecked`。
- 工具拒绝非字符串、空串及超过 200 字符的参数，不再截断后核验另一条表达式。局部导数通过不代表极值、定义域或整段证明通过。

## 验证口径

新增的端到端用例使用真实 WebSocket、SQLite、随包 DKT 权重及明确标注的合成作答事实；生成端使用固定本地测试替身。相同提问在不同历史下产生不同教学指导，且聊天前后学习事件数量不变。这证明链路与边界生效，不证明真实模型回答准确率或学生学习效果提高。

回归入口为 `python scripts/check.py`，包括后端与桌面 Python 测试、前端测试、生产构建及桌面契约。没有本轮付费在线复测，不报告新的四基准成绩。本节记录的是本地改进验收；后续 0.6.4 构建范围见 [发布说明](RELEASE_0.6.4.md)，实际 CI 和安装验收记录随发布产物提供。

本机 macOS 的实际结果：统一检查通过，Python **2167 passed / 11 skipped**，前端 **210 passed**，桌面 Node 契约 **48 passed / 2 skipped**，Next.js 生产构建与 TypeScript 检查通过。Python 跳过项需要未安装的可选 PyMuPDF、训练用 Torch 或专用 sqlite-vec 探测库。额外加入的续写约束用例连同本轮集成文件 **10 项单独回归通过**；其中其余 9 项已包含在统一检查中。目标打包运行时未提供，因此分发安装包验收未执行。这些数量都是工程回归用例数，不是新的数学基准题数或模型答题分数。
