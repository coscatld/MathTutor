# 高中生真实追问与 Agent 辅导改进（2026-10-16）

## 调研依据和难度定位

参考教育部制定、人民教育出版社发布的[普通高中数学课程标准（2017 年版 2020 年修订）](https://www.pep.com.cn/xw/zt/rjwy/gzkb2020/202205/P020220517519489596282.pdf)、教育部考试中心的[2021 年高考数学全国卷试题评析](https://gaokao.chsi.com.cn/gkxx/stpx/stfx/202106/20210607/2192143384.html)，以及安徽师范大学[高中数学学案](https://math.ahnu.edu.cn/__local/C/81/A1/05237961CE6E9BDFEEB3C56C158_83394DED_1697B7F.pdf)的函数零点学习目标。上述文献分别提供素养要求、综合性命题的官方说明和课堂内容组织实例；这里不把旧版文件称为当前唯一版本，也不据此推断实际学生的能力。

高中辅导需要解释知识间的关系、方法选择和推理条件。题目难度不等于计算量，更不等于把一道小学计算拆成更多追问。函数零点需要联系方程、图像、连续性和单调性；高一可以先用函数性质，高年级学过导数后再比较导数方法。

用户提供的三题，本次将其定位为高一函数知识的常规综合应用。这个定位是教学设计判断，并非官方难度系数，不能泛化为某个学生都应该立即会做。

| 原题考点 | 应讲的连接 | 学生可能真正卡住的地方 |
|---|---|---|
| 奇函数、2017 个零点之和、指数方程根区间 | 零点成相反数对 → 和为零 → 构造单调函数定位根 | “2017 有什么用？”“为什么不直接解这个方程？” |
| 指数与分式函数在开区间有零点、参数范围 | 分离参数 → 函数在区间内的值域 → 开闭边界 | “为什么能把 a 移过去？”“这个函数是专门想出来的吗？” |
| 指数/对数分段函数的零点 | 每支解方程 → 回到本支定义域筛选 | “二分之一算出来了，为什么还得扔掉？” |

后续高中评测还应覆盖数列递推与求和、三角恒等变换、向量数量积、圆锥曲线条件、导数与零点个数、概率统计情境。这些是目标范围，不代表本地求解器已支持这些题的完整核验。

## 本轮改变的教学路径

1. 高中模式下，粘贴题目进入 Agent 对话辅导；原题及讨论记录写入已有的本地会话教学上下文。界面可以展开原题，刷新和重启后仍能恢复。
2. 记录原题、学生当前疑问、最近讲过的内容；这些讨论笔记不是判题事件，也不写掌握度。
3. Agent 自主选择苏格拉底式提问、逐步讲解、反例和配图。首次贴题先定位有效入口；学生说“为什么”“看不懂”“这是怎么想到的”时先回答具体疑点，不要求学生用教师提示词引导模型。
4. 显式进入题库或练习协议的可核验题仍使用原有判题与独立/受助/答案后证据。自由对话不会冒充这一证据。
5. 核验器不再把一般函数记号当隐式乘法，也不因端点值或不同分支条件不等价就报数学错误。能核对的计算和明确的等价变形继续检查；真错误保持醒目标注。
6. 每条普通回复前的常规核验文字移动到正文后的折叠“核验范围”。原始披露仍在消息、回放和导出中保留，没有把未经核验的综合推理改称已核验。
7. 高中对话生成预算增加到 4096 token，模型可以选择解释路线、核对局部算式和调用画布；不因局部求解器返回 unchecked 就中止高中教学。

## 试学要求

学生只贴真实题干，并使用自然反应：“我看不懂”“为什么是这样”“为什么要设这个函数”“这是专门想出来的吗”“为什么不包含端点”。不得在学生输入中预置整套讲解路线、指定核验器爱读的两条整数算式，或假扮教师替模型写教学计划。

检查回复是否解释了方法动机和条件、是否保留原题，连续性是否被误用为“有零点必端点异号”，分段函数是否检查各自定义域，以及作图是否越过分支范围。复述“你能说说定义吗”不能算完成一个有具体卡点的追问。

本轮研究与试学属于产品改进验收，不是学习效果实验，不能据此宣称真实学生成绩或掌握度提高。

## 实际试学记录和剩余限制

真实模型完成了三题的自然连续追问，原题始终保留，讨论的独立／受助／答案后证据均为0；没有用自然聊天冒充判题成功。交付截图为13张3200×1800全屏图及7张原生重点裁图，浏览器未出现脚本错误。

框架回归通过不等于模型数学质量通过。试学中曾出现以下问题：把实数集上奇函数在0处为零错误归因于零点总数2017；把分离参数的某种充分适用条件说成必要条件；分段图添加了错误的右支边界点。前者补充了条件关系的提示要求，后者由自然学生质疑触发重画。模型讲解和图形定义仍可能出错，不宣称所有高中推理均已经本地核验，也不能用筛选后的演示截图替代质量评测。

另修复了两个真实完成状态误报：Markdown加粗结尾被识别为乘号、单侧极限方向符号被识别为缺失运算数。对应回归仍要求真正未完成的式子保持未完成状态。学生直接输入短式子（如a=2）也只更新当前尝试，不覆盖已保存原题；明确的新题再建立新的讨论上下文。
