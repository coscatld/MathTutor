# MathTutor 0.7.1 更新说明

日期：2026-10-27（Asia/Shanghai）。正式名称：**MathTutor——基于学习过程追踪与可验证解题的开源数学智能辅导系统**。

0.7.1 汇总 0.7.0 之后的可靠性升级，并修复图形交互与删除草稿问题。学生输入在失败后保留，图形在聊天刷新时保持操作状态，学习记录、资料来源和本地服务继续按明确的证据与权限边界工作。

下载、平台文件与对应验收记录见 [0.7.1 发布页](https://github.com/coscatld/MathTutor/releases/tag/v0.7.1)。历史 0.7.0 r3 文件继续保留其原构建内容，各版本资产分别对应自己的源码与验收记录。

## 本次图形与草稿修复

- **删除成功后再清理**：取消不发送删除请求；服务失败或断网保留文字、图片和当前页面。异步等待期间产生的新输入和资料范围继续保留，删除结果有单独反馈；重复点击不会重复执行删除。
- **图形状态跟随内容**：聊天刷新、工具面板切换、追加消息或相同内容的新对象，保留场景参数、轨迹和暂停状态。场景内容变化时才重置。
- **函数数值查询**：函数图增加带标签的 x 输入、读取按钮与逐曲线结果表，保留原鼠标读数。输入校验覆盖有限数值、范围和端点；结果按采样点线性插值，分段缺口显示“无定义”，不跨段插值。仅提交查询时更新 polite 状态通知。
- **窄屏图形控件**：标签、数值、滑块和按钮按容器宽度分行，长内容可换行，控件操作高度保留 44px。界面不新增按键或按钮操作的小字提示。
- **离屏停止动画计算**：只有前台且处于聊天可见区域的图形继续调度动画。返回可见区域后恢复原本希望播放的参数，手动暂停保持暂停；卸载时清理观察器、监听器和动画帧。减少动态效果偏好继续生效。

实现、截图、复现命令与 CPU profile 见 [10 月 27 日图形与删除草稿记录](https://github.com/coscatld/MathTutor/blob/v0.7.1/docs/10月27号更新文档/001-图形交互与删除草稿修复.md)。

## 近期升级汇总

### 启动、练习接受与资料恢复

`npm run dev` 使用显式 development 浏览器启动器，并默认监听本机。403 提示配置问题并停止自动重试；临时网络或服务未就绪仍可恢复。生产模式继续执行来源与身份检查。

练习接受操作覆盖会话读取、状态同步、WebSocket 接受和子会话读取，防止重复进入，取消与卸载会释放本次请求、连接和定时器。离开保护保留文字、图片、资料范围与笔记草案；题目变化后，旧作答草稿需要重新确认用途。

资料导入把“文件已导入”和“归属已应用”分开处理。原生选择器明确不支持时才使用浏览器选择器；归属失败可单独重试，列表刷新失败保留成功结果。解析反馈区分可检索、警告、需 OCR、失败、检索停用和未归类。见 [10 月 26 日记录](https://github.com/coscatld/MathTutor/blob/v0.7.1/docs/10月26号更新文档/001-启动与学习交互修复.md)。

### 学习证据、画像与迁移练习

独立作答、受助作答、看答案后的作答和自我报告使用一致分类。缺少具体技能定位的多技能错误保留为可查证的整题观察；同题后来答对保留原观察及其纠正状态，具体技能仍需独立检验。

新题邀请核对学生完整保留的规范题历史，并在最终发布事务重新检查，避免生成期间新增曝光造成重复。复习可以重做，目的明确标识。候选耗尽给出失败与重试路径。画像按下一步、实际观察和阶段复盘组织，覆盖数量与掌握判断分别显示。见 [10 月 24 日教学证据与迁移题记录](https://github.com/coscatld/MathTutor/blob/v0.7.1/docs/10月24号更新文档/003-教学证据与迁移题可靠性.md)。

### 检索、预算、备份与评测门

重解析在同一次写入中使旧向量失效，拒绝发布基于旧切片计算的嵌入。最终证据包同时受单项与总量预算约束，文本、哈希与来源同步；结构化父题干与解答完整保留或舍弃。每日费用与 token 用量按完整 UTC 日统计，知识问答为最终生成、检查与修复保留步骤。

备份保留数量按真实候选计算，异常文件不挤掉正常候选；目录、散列、清单和清理工作进入受管理 worker。PDF 解析修复中文标题的字号判断；旧资料沿显式重解析流程更新。多轮评测拒绝空结果、零检查、未知场景和失败终态，合法子集报告实际覆盖，完整发布门只接受全套覆盖。中文 CLI 输出统一 UTF-8。

细节与历史结果见 [产品可靠性记录](https://github.com/coscatld/MathTutor/blob/v0.7.1/docs/10月24号更新文档/001-产品可靠性与阅读体验.md)及 [教学证据记录](https://github.com/coscatld/MathTutor/blob/v0.7.1/docs/10月24号更新文档/003-教学证据与迁移题可靠性.md)。

### 本地服务、资源边界与插件开发

HTTP 与 WebSocket 统一检查精确 Host、Origin、变更请求的 CSRF 条件，以及桌面每次启动的随机凭证。上传按实际收到的字节计数，超限返回 413；解析任务有准入队列、页数、文本与资产预算。文档元数据、切片、全文索引和向量失效在一次事务发布。见 [10 月 25 日记录](https://github.com/coscatld/MathTutor/blob/v0.7.1/docs/10月25号更新文档/001-本地服务安全与资源边界.md)。

插件开发增加 Python／TypeScript 模板、构建和正式导入规则检查，以及明确接口子集的 TypeScript 工具适配。源码 CI 使用 Node 24，并实际执行带类型注解的文件后再运行插件测试。代码插件仍需单独的本地代码信任与数据授权，按当前账户权限执行；其结果继续作为参考材料，不自动写入数学核验、掌握度或 DKT。见 [插件开发指南](https://github.com/coscatld/MathTutor/blob/v0.7.1/docs/PLUGIN_DEVELOPMENT.md)。

官网的中英文任务入口、知识库与学习证据指南同步完善，已有线上验收对应其记录的部署提交。见 [官网部署与线上验收记录](https://github.com/coscatld/MathTutor/blob/v0.7.1/docs/10月24号更新文档/004-本轮提交部署与线上验收.md)。

## 升级与数据

升级前创建并验证应用内备份，正常退出旧版，再替换安装。数据库 migration head 保持 **024**，本版未新增结构迁移；数据库备份仍以 SQLite 为范围，社区与插件配置需要单独保存。恢复数据库后，插件重新停用并清除数据同意，目录授权需要重新授予。

学习资料与数据库保存在本机；使用外部模型服务时，当前问题、上下文和选中的资料片段按现有规则发送给用户配置的服务商。本次没有读取真实学生数据库、训练模型、更新权重、执行付费模型评测或重新评分历史基准。来源域 ASSISTments 数据与 MathTutor 真实学生数据分别统计，现有分数继续对应原被测提交和样本。

macOS 的本地 ad-hoc 签名、Developer ID 和公证是不同验收项；Windows 的 Authenticode 同样单独检查。各平台签名和首次打开方式，以该版本实际资产记录及 [Mac 安装说明](https://github.com/coscatld/MathTutor/blob/v0.7.1/docs/MACOS_INSTALLATION.md)为准。
