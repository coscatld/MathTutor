# 社区：题库共享与教学插件

社区入口位于侧栏和知识库页。资源通过公开 GitHub 原始文件或用户选择的 HTTPS 源流转；个人资料与学习记录留在自己的应用中。主页面提供“发现资源”“我的插件”“创作与分享”；需要订阅其他目录时，再打开“社区来源”。

## 找到并使用资源

1. 在“发现资源”搜索名称、作者、知识点或标签，按题库 / 插件、学段、收藏和已添加筛选。
2. 打开详情，查看作者声明、许可证、版本、更新说明、所需权限和可用的正文预览。只有目录描述的远程资源会明确显示尚未下载正文。
3. 题库添加为自己的可编辑知识库副本。它不会覆盖先前编辑，也不会自动加入当前对话；在“对话资料”选择后才供该对话参考。
4. 插件导入后出现在“我的插件”，先阅读它需要哪些数据，再点“同意并启用”。调整设置、运行、“保存结果”、停用和卸载都在这里完成。保存的结果是可直接阅读的文本。

已经从社区下载了插件？点“导入下载的插件/资源”，选择文件即可。应用会自动识别插件或题库：插件直接加入“我的插件”，题库直接进入个人知识库。无需解压、编辑内容或先配置来源。插件仍需本人同意后启用。

收藏、资源源和导入历史按当前用户保存。题库的新版本建立新的个人副本；旧版本和自己的修改仍保留。插件升级保留用户配置，并重新停用，要求确认当前权限；同版本不能悄悄更换内容。

随应用提供的两个题库和三个插件明确标为“项目示例”。目录没有虚构下载量、评价、热度或社区成员。真实社区资源来自用户订阅的目录；详情可以通过作者提供的项目、问题反馈和讨论链接参与 GitHub 协作。

## 更多社区来源

常用资源可以直接在“发现资源”点“导入”，也可以下载后把文件分享给他人。应用随附少量项目示例，更多资源由创作者分享。

需要持续查看某位创作者的更新时，打开“社区来源”，粘贴对方提供的公开 HTTPS 原始文件地址，添加后点刷新。支持 GitHub 公开目录和自定义来源；使用 GitHub 时应复制 Raw 地址，普通仓库网页通常无法作为资源目录读取。

刷新只读取资源清单，点“导入”或“下载”时才取得具体资源。下载会自动检查内容完整性；失败会保留原来的资源和编辑内容。移除来源也不会删除已经导入的题库和插件。

资源分享文件通常以 `.mathtutor` 或 `.mtplugin` 结尾，应用也兼容旧格式文件。开发者需要的目录协议、字段和发布步骤见[插件开发指南](PLUGIN_DEVELOPMENT.md)，题库结构见[共享题库说明](SHARED_QUESTION_PACKS.md)。普通使用无需编写这些文件。

## 创作与分享

“共享题库”从当前保存的个人知识库生成社区包，包含编辑后的 Markdown、文件夹路径、版本、说明、作者和许可证。可选填写项目主页、问题反馈和讨论地址。下载后由创作者发布到选择的 GitHub 仓库或 HTTPS 站点；应用不会自动公开个人资料。

“创建教学插件”先选择“组一套练习题”“整理错题”或“查看学习变化”，再填写名称、作者、用途和使用说明。题目数量、练习年级等用表单调整；版本和分享许可收在“分享设置”。点“保存插件”就会生成可直接导入的文件，可以分享给朋友，也可以自己导入试用。保存文件不自动安装或启用插件。

社区插件是声明式数据，组合应用已有工作流；新的执行算法由维护者增加受控处理器，或通过可信的 [Python SDK](CREATOR_EXTENSIONS.md) 接入。插件机制、三种实际工作流、权限和统计口径见[社区教学插件](COMMUNITY_PLUGINS.md)。

## 数据与运行边界

社区源只提供目录和内容包，不接收学生记录或插件运行结果。页面上的组卷与统计在本地服务中执行，不调用付费模型；用户在对话中调用已启用插件时，结果的有界片段会提供给当前配置的模型。

内容哈希检查完整性，不证明作者身份、许可有效性或数学答案正确。导入题库是参考资料，不能自动成为学习判定、学生掌握状态或 DKT 成绩。没有作答记录时，趋势与错题保持为空。

收藏、订阅、历史与插件设置是应用私有目录中的独立 JSON，不包含在现有 SQLite 数据库备份中。换机前请导出资源和插件包，并保存自己的源地址。恢复数据库成功后插件停用并清除数据同意；若权限重置阶段磁盘写入失败，数据库回滚，部分插件可能已安全停用，需要重新确认权限。重置社区状态只清本人的源、收藏和历史，不删除个人题库或插件。

导入资源与社区历史位于两个存储系统。历史保存失败时，题库导入会补偿撤回本次新建副本；插件已安装成功时会返回真实结果和历史未保存提示，不把跨存储操作标为原子事务。

远程读取保留系统 TLS 证书和原域名校验，固定连接已检查的 DNS 地址，禁用重定向、环境代理、登录凭据和 Cookie，限制大小、时限和并发。通常拒绝所有私网和保留地址。为兼容已有 VPN 的 Fake-IP 模式，仅精确的 `raw.githubusercontent.com:443` 可使用 DNS 返回的 `198.18.0.0/15`；仍验证 GitHub 域名证书，不接受该 IP 的字面地址，也不将例外扩大到自定义域名。

## 工程验证

```bash
python -m pytest tests/test_community_resources.py tests/test_community_fetch.py \
  tests/test_community_plugins.py tests/test_community_plugins_api.py \
  tests/test_community_file_import.py tests/test_plugin_bundle_cli.py -q
cd web
npm test
node scripts/smoke-community.mjs
```

浏览器脚本需先启动隔离的前端服务，可使用与其他 smoke 脚本相同的 `LAYOUT_URL`、`PLAYWRIGHT_MODULE` 和 `CHROME_EXECUTABLE`。浏览器夹具验证界面与操作，不代表真实社区用户规模或教学质量分数；后端测试另使用实际 SQLite、题库和学习事件验证数据与权限。
