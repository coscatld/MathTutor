# 社区：导入题库与插件

社区分为“发现资源”和“我的插件”。“发现资源”用于导入并查看你自己的资料，“我的插件”用于导入和管理插件；两个入口分别处理文件，不展示推荐内容。

## 发现资源：导入自己的资料

点击“导入文件”选择 Markdown、TXT 或已有题库文件，也可以点击“导入文件夹”，一次选择笔记目录。文件夹中的 `.md`、`.markdown` 和 `.txt` 会保留相对路径；图片、隐藏配置和其他文件会跳过并显示提示。

资料进入个人知识库，导入后可以编辑、保留版本并导出。在对话中的“对话资料”选择后，才供该对话参考。资料与插件使用独立的导入入口，选错文件时会提示重新选择。

直接文件或文件夹导入最多 1000 份文本、合计 20 MiB、每份文本 1 MiB，文字须为 UTF-8。已有题库支持 `.mathtutor`、`.json` 或 `.zip` 格式。导入会检查路径、文件类型和完整性；检查通过不等于作者身份、许可或题目答案已经得到认证。

## 我的插件

点击此页的“导入插件”，选择已下载的教学插件文件，或开发者提供的 `.py`、`.ts`、代码 `.zip`。插件默认停用，阅读需要的数据权限并“同意并启用”后使用。此入口只接收插件，不能导入资料或文件夹。代码插件还需要明确勾选信任本地代码；代码以当前本机账户权限运行，可访问该账户的文件和网络，不是操作系统沙盒。

可以调整设置、运行、保存结果、下载插件文件、停用和卸载。保存的结果是可直接阅读的文本。

目前支持组卷、错题整理和学习趋势三类功能。组卷读取实际课程题库；错题与趋势读取当前用户的真实记录，没有记录时显示空状态。学习趋势是已记录独立作答的统计，不是掌握率、DKT 预测或标准化成绩。

在对话中输入 `/` 可以选择已启用且运行时可用的插件，补充参数后发送。宿主会实际执行插件，再把结果交给当前模型；选择候选本身不运行代码。

同一包重复导入保持现有状态。插件升级保留个人设置，并重新停用，需再次明确同意启用；同一版本不能悄悄替换内容。题库新版本建立新的个人副本，保留旧库与用户自己的修改。

## 数据与恢复

三类内置教学工作流在本地服务执行，不调用付费模型。自定义代码的行为由作者实现，启用前应审查和信任。用户在对话中实际调用插件时，结果的有界片段会提供给当前配置的对话模型。题库参考答案与插件结果不会自动变成数学核验证据，也不写入学习判定或 DKT 成绩。

插件设置和社区导入记录独立保存在应用私有目录，不包含在现有 SQLite 数据库备份中。换机前可下载插件文件并导出个人题库。恢复数据库成功后，插件停用并清除数据同意，需重新启用。

导入资料与保存社区记录涉及独立存储。记录保存失败时，题库导入会撤回本次新建副本；已经成功安装的插件会如实返回结果和记录未保存提示。

## 开发者文档

插件编写、测试、打包和发布见[插件开发者指南](PLUGIN_DEVELOPMENT.md)，仓库提供三个可运行示例和离线打包工具。开发者生成文件后，使用者即可在社区直接导入。

题库和资料库的格式见[共享题库说明](SHARED_QUESTION_PACKS.md)，权限与统计口径见[社区教学插件](COMMUNITY_PLUGINS.md)。自己的算法可以使用[Python / TypeScript 代码插件](CODE_PLUGINS.md)，也可以通过可信的 [Python SDK](CREATOR_EXTENSIONS.md) 接入；接口用法集中在开发文档中。
