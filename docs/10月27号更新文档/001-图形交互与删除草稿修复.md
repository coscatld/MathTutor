## 复现

在 `web/` 中执行：

```sh
npm test
npm run build
npm run dev -- --port 3198
```

浏览器脚本使用 `LAYOUT_URL=http://127.0.0.1:3198`，依次运行上述五个 smoke 脚本；如未在项目中安装 Playwright，可通过 `PLAYWRIGHT_MODULE` 指向已有模块，通过 `CHROME_EXECUTABLE` 指向本机 Chromium／Chrome。本次复用本机现有工具，没有新增依赖。
