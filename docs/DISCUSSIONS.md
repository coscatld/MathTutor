# Discussions 使用指南

GitHub Discussions 适合讨论设计、题库范围和贡献方式。是否已经在仓库中打开 Discussions，以 GitHub 仓库 Settings → General → Discussions 为准。本页不假定该开关已经打开。

## 适合 Discussions 的话题

- 题型覆盖与文档措辞
- 插件或题库格式的使用问题
- 官网 / Docs 的导航与翻译
- 非安全类的产品方向

## 应使用 Issue / PR / 私密披露的话题

- 可复现缺陷：Issue（Bug report）
- 具体代码改动：Pull Request
- 安全漏洞、密钥泄漏、可识别学习数据：按 [SECURITY.md](../SECURITY.md) 私密披露，不要发在 Discussions

## 发言边界

- 使用虚构或已脱敏例子。
- 不要把“测试通过”说成“真实教学效果已验证”。
- 不要虚构 Stars、下载量或准确率。

如果 Discussions 尚未启用，请先在 Issue 中讨论，或由维护者打开该功能后再使用分类。
