# MathTutor 0.6.2 发布说明

修复只说「画双曲线」时反复要求提供公式、接着说「都可以」又退回文字聊天的问题。

## 作图

- 「画一个图展示一下双曲线」直接显示标准双曲线示例，说明所选方程，提供 a、b 参数滑块。未配置模型时同样可用。
- 椭圆、抛物线、反比例函数、正弦函数、余弦函数也可选择标准示例。学生已给出方程、坐标或其他条件时，保留这些条件，不用默认示例替换。
- 「都可以」「你定」「画吧」续接最近的作图请求，支持升级前已经保存的对话。更换话题或已交付图形后不会重复触发原请求。
- 讨论相关数学概念和简短追问时，模型可主动调用交互画布；未指定参数时允许自行选择示例并说明。
- 模型仍通过 `draw_scene` 提交定义，由本地引擎校验、计算和绘制。数学核验提示、原题答案披露规则和学习证据记录继续生效。

## 验证与边界

作图、场景编译、模型工具调用、流式回复和教学状态的 237 项定向回归通过，其中新增 28 项作图自主选择与上下文检查。隔离数据目录的浏览器验证确认：输入原话后显示双曲线，a 从 2 改为 3 时画布重绘，页面 JavaScript 错误为零。模型工具调用回归使用模拟供应商响应，本次没有重新评估真实模型的讲解质量。

三平台完整检查与 Windows 安装验收以本次发布页链接的 GitHub Actions 记录为准。[本机修复验证记录](qa/drawing-autonomy-2026-10-15.md)保留了发布前的验证范围。

## 更新

关闭旧版 MathTutor，运行 `MathTutor-0.6.2-win-x64.exe` 安装后重新打开。保留现有用户数据目录；数据库版本仍为 024，从 0.6.1 更新无需新增数据库迁移。

Windows x64 安装包未签名，随包提供 blockmap、SHA-256 校验文件及安装验收记录。macOS 最近发布的安装包仍为 0.5.0。
