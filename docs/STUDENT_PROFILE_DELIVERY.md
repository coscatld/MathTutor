日期：2026-09-13。基于当前工作区增量修改，保留原有未提交的桌面、资料与会话功能改动。本次没有提交 Git commit、推送或创建远程 PR，也没有训练或分发真实学生模型。

## 1. 已补齐的方案契约

`STUDENT_MODEL_IMPLEMENTATION_PLAN.md` 已明确五项约束：首次标签的时间顺序与排除占位、A 的内部概率公式、新学生与新题冷启动的分离、模块增益与产品选型的分离、完整推理流程及删除代次的包级自检。页面部分加入已有问答但缺独立证据的空态、进行中练习优先和新增证据直达入口。

## 2. 已实现的关键路径

| 能力 | 实现与行为 |
| --- | --- |
| 首次独立标签 | `prior_task_attempt` 结合序列级 `ordered_attempts()`；先错后提示仍保留 0，未知首次不会被后续成功替代，后续重复作答保留为历史 |
| 呈现时预测 | 题目开始前写入 `presentation:<cycle>` 的历史截点和预测；首次整题作答仅关联一次结果，后续提示/作答不覆盖 |
| 排除判定 | 保留原始作答与顺序，追加失效事件，重算画像；历史预测保留原始数值并标记标签已排除；帮助暴露事件不可由此入口撤销 |
| 删除与重放 | 新增持久化 `learning_generations`；同一档案跨会话串行协调；重放提交比较代次、事件上界和模型版本，旧代次结果被拒绝 |
| 完整删除 | 删除事件、预测、快照及推荐反馈；移除首次资格占位，保留聊天但不从聊天恢复证据；只保留不含作答内容的删除代次 |
| 学习画像 | 新增 `/math-tutor/profile`，先展示观察，计数渐进展开；证据明细包含实际题目、用户作答、核验结果、帮助状态和原会话入口 |
| 空态与联合证据 | `mastery=null`；有问答但缺独立作答时解释数据范围；联合题证据单列，不把它混成每个技能的独立成功或诊断成绩 |
| 数据与隐私 | 从侧栏“我的数据”移入设置，复用资料/记忆/学习历史删除及导出；检索索引重建与学习画像重算分开 |
| 推荐列表 | 进行中练习优先，接受与完成分开；一个主推荐、最多两个备选；稍后/不相关反馈不写作答标签 |
| 继续与完成 | 服务端先恢复对应子周期再导航；周期 API 返回可打开的会话标识；完成摘要直接链接到本次证据 |
| 纠错后的推荐 | 排除或完整删除学习证据时撤回该档案的待开始建议；已经接受的题目保留原子周期 |
| 冷启动划分入口 | `student` 明确允许跨学生共享课程题；新增 `student_item`、`student_family` 联合留出协议；同一事件重复导入去重 |

新增数据库迁移 `018_learning_profile.py`，现有数据表分类与迁移测试已同步。新增表只有删除代次和推荐反馈；事件的首次资格字段由旧事件历史兼容推导。
