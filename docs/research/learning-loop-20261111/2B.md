2026-11-11。仅阅读任务与公开原始研究，未查看生产代码、私人学生数据，也未运行训练。以下门槛是本项目建议，尚无实验结果。

## 核实的一手证据

| 来源 | 已核实结论及适用边界 |
|---|---|
| [Guo 等，ICML 2017](https://proceedings.mlr.press/v70/guo17a.html) | 准确率与概率校准不同；温度缩放在独立验证集拟合。结果来自图像和文本分类，不能直接证明诊断可信。 |
| [Geifman 与 El-Yaniv，SelectiveNet，ICML 2019](https://proceedings.mlr.press/v97/geifman19a.html) | 拒答应同时评估风险与覆盖率；只报告被接受样本的准确率会隐藏大量拒答。 |
| [Golovin 等，NIPS 2010](https://proceedings.neurips.cc/paper_files/paper/2010/hash/1e6e0a04d20f50967c64dac2d639a577-Abstract.html) | EC2 研究含噪主动辨别；贪心信息增益存在失败情形。保证依赖已指定的假设、先验与观测模型。 |
| [Liu 等，pyKT，NeurIPS 2022](https://arxiv.org/pdf/2206.11460) | 同题拆成多知识点后逐一预测会泄漏标签；应按完整题目预测和评估。响应正确不等于直接观测到知识状态。 |
| [Kapoor 与 Narayanan，泄漏研究](https://arxiv.org/abs/2207.07048) | 原始分类与复现研究指出时间泄漏、重复样本和训练测试依赖；本轮核查预印本，不引用跨版本统计数字。 |
| [Jiang 与 Li，ICML 2016](https://proceedings.mlr.press/v48/jiang16.html) | DR 离线策略评估结合模型与重要性权重；需要适当行为策略概率、支持范围及独立评估。不能补出未观测学习结果。 |
| [Rafferty 等，Cognitive Science 2016](https://onlinelibrary.wiley.com/doi/full/10.1111/cogs.12290) | POMDP 教学把测量和教学纳入序列决策；两项概念学习实验支持可行性，但假定学习模型已知。 |
| [Lindsey 等，Psychological Science 2014](https://journals.sagepub.com/doi/10.1177/0956797613504302) | 时间匹配复习通过学期后累计测验衡量保留；外语研究不能直接外推数学迁移。出版摘要已核实。 |

## 建议与实验门槛

**Tier 1：有限预算的主动诊断闭环。** 将单次错答后的标签匹配改为竞争假设集合，显式保留“偶发失误”和“未知”；选择能区分假设的自由作答探针，最多追加两题，再决定定向练习或暂不判断。这是任务与状态架构改变。借鉴 EC2/POMDP，不宣称复现其理论保证。先在少量验证器支持的概念实验，之后才考虑集成。

使用 seed=0，对比被动诊断、等预算随机探针、单模型信息增益与候选方案。策略和模拟学生必须分离；测试稳定误解、随机失误、复合误解、未知规则、提示污染和答题中学习。调参、校准、最终测试按模拟学生及实质题族隔离；换数字、翻译、重试不算新题族。真实数据未来还须时间前向切分；同次作答所有知识点保持同组。

报告选择性错误率、覆盖率、未知误判率、每次正确辨别的题数，以及风险—覆盖曲线。建议通过门槛：可辨别测试层至少接受 200 例，错误率的 95% 上界≤5%；同覆盖率下较随机探针错误率下降≥25%，或同风险下题数下降≥15%。未知压力层错误确诊率≤5%；样本不足判为证据不足。阈值需预注册，不能看最终测试后调整。

**Tier 2：** 证据去重、暴露标记、可撤销诊断、固定间隔复习与独立迁移首答计数；有独立标签后再校准概率。零容忍门槛为跨用户证据串用、未验证答案记为正确、取消响应写入证据和超过探针预算。

模拟器胜出只支持离线流程改进；DKT AUC、熵下降和历史 WS 检查均不能称学习增益。未来真实学习评估应按学生随机分组、匹配练习时间，预注册 7 天和 28 天无提示测验，将同构保留与未见结构迁移分开报告，并记录退出和缺测。当前缺少学生数据与行为概率，不开展因果 OPE。该方案属非训练实验；由根任务检查硬件后确定运行预算，无需预设 GPU 训练。
