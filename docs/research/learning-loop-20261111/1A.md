# 1A 文献综述：把数学误概念变成可检验的学习闭环

检索日期：2026-11-11。范围：数学领域知识、数据表示与任务架构。依据为任务目录中的 `task.md`；未检查产品源代码、学生数据或账户数据。以下是实验建议，未执行实验，也未声称已经产生学习收益。采用 research 技能的 1A 子任务流程。

## 结论与建议

优先实验 **“可执行误概念假设 → 区分题 → 独立复查 → 跨表征迁移”**。新增对象应是一个带来源和反证的概念检查过程：系统保留几个能够解释当前作答的候选规则，选择能够区分这些规则的题目，再决定需要什么复习。它与现有 skill 分数、error concept observation、DKT shadow prediction 的区别，是显式记录“哪些解释仍成立、下一道题能排除什么、何种独立证据才足以结束检查”。

这一方向有三层依据：可执行错误程序可以预测学生会在哪些题上出错；数学概念的变化不能只用总正确率描述；已有认知诊断研究把选题建模为减少候选状态的不确定性。这些依据分别来自历史算术诊断、真实小学数学测量和测量模型研究，不能相互替代。[Brown 与 Burton，1978](https://doi.org/10.1016/S0364-0213(78)80004-4)、[Durkin 与 Rittle-Johnson，2015](https://doi.org/10.1016/j.learninstruc.2014.08.003)、[Cheng，2009](https://doi.org/10.1007/s11336-009-9123-2)。

首个实现宜限制在本地验证器确实支持的两到三个题族。没有校准过的似然、先验和学生反应数据时，先使用规则预测与集合排除，并把结果称为“待核实/已有重复证据/存在反证”，不显示伪精确的心理状态概率。

## 检索与取证方法

定向检索了 procedural bugs、decimal misconceptions、correct/incorrect worked examples、solution comparison、cognitive diagnostic adaptive testing、Eedi explanation benchmark 和 correct-answer misconceptions。纳入 8 项一手来源：原始论文、论文作者提供的摘要及原始基准说明；没有把综述、排行榜解读或厂商成效宣传作为效果证据。经典研究用于稳定的数学教育机制，2025–2026 研究用于检验近期数据及部署判断。期刊年份以卷期/论文为准；例如 Cheng 的论文属于 2009 年，Cambridge 页面显示的 2025 年上线日期不是研究年份。

部分文献仅核验到作者摘要或公开页面，表内明确标出。未进行系统综述级别的穷尽检索或偏倚量化。本综述没有估算、拼接或补写未核验的效应量。

## 对数据与任务表示的具体启发

### 1. 概念检查要保存“可被下一题反驳的解释”

建议增加局部 `ConceptCheckEpisode`，每个 episode 只涉及一个数学关系及少数候选规则。其状态应能区分：等待第一次作答、解释有歧义、需要区分题、已有重复证据、准备复习、正在迁移检查、已获得本次独立证据。它不是永久的学生属性。

建议字段：

- `targetConcept`、适用输入域、前置条件与版本化规则 ID；规则能对一个合法题目计算预测答案或步骤模式。
- `candidateHypotheses`：正确程序、目标错误规则、未建模/偶发失误的余量。多个假设可同时保留；保留“无法判定”。
- `evidence`：题目与模板 ID、原始作答事件 ID、数学验证结果、方法证据类型、支持/反证、是否首次独立尝试、提示和选项暴露、时间及 owner。
- `probeSignature`：每个候选规则在每个候选题上的预测，及该题是否确实区分它们；同一答案可由多个规则产生。
- `followup`：待复查概念、复习资格时间、优先级原因、迁移变换类型。记录调度原因与实际完成的证据，避免“已展示”被记为“已学会”。

这是由 S1、S5 推导出的产品架构建议，不是论文已经验证的状态机。学生自报信心可以是可选辅助证据，不应直接决定能力等级；解释长度不足应保留未知，而不算推理错误。近期 S7 提供了这种区分的现实动机。[S1](https://doi.org/10.1016/S0364-0213(78)80004-4)、[S5](https://doi.org/10.1016/j.learninstruc.2014.08.003)、[S7](https://arxiv.org/html/2606.23205v1)。

### 2. 题目需要“诊断签名”和“迁移关系”，不只是技能标签

诊断题回答的是“哪个解释还可能成立”；教学例题回答的是“应注意哪个关系”；迁移题回答的是“能否在改变的条件下独立应用”。三者应有独立用途字段，即使共享同一知识点。

可用一个本报告构造的精确算术示例说明：学生在 `(-9)-(-5)` 上得到 `-4`。正确减法规则与“绝对值作差后统一加负号”的错误规则在此给出相同输出，单凭结果无法区分。交换两数后，`(-5)-(-9)` 的正确值为 `4`，错误规则仍给出 `-4`。因此前一题的答对可以是数学上正确、方法尚未可知；第二题才提供区分信息。示例只用于展示可识别性，不宣称所有给出 `-4` 的学生都采用了同一错误规则。

为每个 probe 预计算“正确答案与错误程序预测是否碰撞”；如果碰撞，标注为低诊断性题，而非把做对它当作目标概念的充分证据。若题库找不到能区分剩余假设的合法题，应报告未辨明，不能靠重复同类题提高置信状态。选题可从最大化预测答案分组的分离度起步；有真实校准数据后才讨论完整后验信息增益。[S2](https://doi.org/10.1007/s11336-009-9123-2)。

迁移关系至少区分：只换数值、改变正负/运算方向、改变表示形式、改变表面情境、增加组合步骤。首次独立作答必须单列；看过同构示例、选项或提示后的正确仍有练习价值，但不能进入未暴露迁移的分母/分子。

### 3. 正误对比材料应与“需要区分的关系”对齐

候选教学卡先呈现经验证的正确和错误步骤，问一个具体问题，例如“哪一步改变了等式两边的关系”，再展示纠正说明，之后进入新的独立题。错误内容必须明确是供辨析的例子，不能混入解答权威链。S3 支持特定小数材料中的正误对比；S4 支持解法比较对程序灵活性的价值。这里不能推出任意并排展示、额外文字或未经核验的生成式错误都有益。[S3](https://doi.org/10.1016/j.learninstruc.2011.11.001)、[S4](https://doi.org/10.1037/0022-0663.99.3.561)。

## Tier 1 假设与离线预注册建议

**类别：** 任务范式和学习者状态架构重构；把“错答分类后给同技能题”改为“竞争解释下的主动测量与分阶段复查”。

**假设 H1：** 如果用精确的错误规则预测构建题目诊断签名，并在相同最多三次追问预算内选择能区分剩余解释的题，那么在冻结的规则外推测试中，系统会比按技能随机/固定顺序出题更准确地区分目标错误规则，同时降低对偶发失误和未知规则的错误确认。理由是候选题的诊断信息不同；这是由 S1、S2 导出的**待检验假设**。[S1](https://doi.org/10.1016/S0364-0213(78)80004-4)、[S2](https://doi.org/10.1007/s11336-009-9123-2)。

**假设 H2：** 如果复查与迁移都使用新的独立作答事件，并保留暴露和模板关系，那么模拟事件流中的“错误关闭检查”和“重复/提示作答冒充保持或迁移”将减少。H2 是证据记账与状态机正确性假设，不是学习效果假设。

**数据冻结：** 实现者应先检查验证器真实支持域，再冻结 2–3 个题族和每族 1–2 个有明确定义域的错误程序。建议优先考虑有符号算术、小数大小或单步分配律；是否可用须由源代码与验证器检查确定。本综述没有把它们标为已支持。

建议主评估建立 300 条独立合成 episode：3 个最终支持题族 × 5 种响应机制 × 20 条轨迹；若只能支持 2 族，则预先固定为 200 条，不能看结果后删掉困难题族。五种机制是正确规则、目标错误 A、目标错误 B、单次偶发失误、混合/未建模规则。先以少量单独开发样例调试，冻结测评生成规范及哈希后再运行。参数值、题面和错误输出由独立 oracle/手写反例核验；不能让待测系统的同一判定函数生成所有金标签。按结构模板族隔离开发与测试，不能只换数值后宣称跨题型泛化。

这套模拟器只能回答“在明确指定的机制下能否分辨、调度和记账”。不得设置“接受辅导就自动学会”的模拟转移，再把增加的正确率称为学习增益。新随机过程统一 `seed=0`；额外机制条件为预先列出的压力测试，不能替换为挑选最好看的 seed。

### 主要指标、分母与决策门槛

以下阈值是建议的工程预注册值，不是文献确认的临床/教育诊断阈值；父实验可在首次运行前调整并记录原因。

| 指标 | 定义与分母 | 建议判据 |
|---|---|---|
| 限额诊断表现 | 在最多三次追问后，对可识别的已知机制计算 macro-F1/混淆矩阵；同时报告全体 episode 中覆盖率和未判定率。 | 相对 C1 的 macro-F1 提高至少 0.05；各题族单列，不能仅报总体。若离线改进不稳定，回退 Tier 2。 |
| 错误确认率 | 将正确、偶发失误、未建模机制确认为某个稳定目标错误的 episode 数 / 这些 episode 总数。 | 不劣于 C1；对未建模集合错误确认建议不超过 5%。同时检查已知机制召回，防止全弃答达标。 |
| 区分题有效率 | 所选题真正令尚存候选产生不同预测的次数 / 存在可用区分题的选题次数。 | 精确无噪声条件要求 100%；不存在区分题时应保留未判定。 |
| 偶然答对覆盖 | 初始答案恰好正确、但错误程序在可用变式上会失败的轨迹中，被后续独立题分辨的比例。 | 必须单列；不能把“系统看到了隐藏解释真值”混入输入。 |
| 闭环证据完整性 | 关闭 episode 所需的独立事件、时间与迁移关系齐全的次数 / 全部关闭次数。 | 100%；缺字段、只有示例暴露或同题重复不允许关闭。 |
| 状态污染 | 取消响应、重复请求、跨 owner、提示/答案暴露、时间倒序、旧版本规则造成的非法进度/调度写入。 | 固定边界用例中零次；任何一例是发布阻断项。 |
| 开销 | 每次选题的 CPU 墙钟 p50/p95、峰值内存、平均追问题量与无法出题率。 | 硬件检查后预先定预算；建议以不影响实时交互的 50 ms p95 为初始工程目标，必须实测，不冒充结果。 |

主表同时提供分子/分母、各域及各机制结果。对合成随机轨迹可用配对重采样区间，但必须标为“模拟条件内的不确定性”；不能推断现实学生人群效果。似然没有用真实数据校准时，熵下降只是算法内部读数，不能作为“学生理解提升”指标。

### 学习闭环与延迟检查

在离线测试中注入显式时间：即时重复、跨会话但未到期、到期首次作答、晚到、时区切换及取消。保持与迁移必须有单独的首机会分母。时间到期只代表可以检查，不能触发概念自动遗忘或自动掌握。建议区分“当前正确证据”“延迟正确证据”“迁移正确证据”，不合并成一个永久 mastered 布尔值。

是否真正改善保持/迁移，需要后续真实学生、相同时间和内容暴露下的对照评估，并以预定延迟、未曝光新题和独立评分为结果。当前任务给出的 16 场景 WS 回归和历史检查数只能证明特定产品行为与数学验证结果；既不能作为教学随机试验，也不能重新命名为学习增益。

### 运行计划与资源

本实验是非训练的规则/策略实验，不需要训练模型或申请 GPU。父实验应先报告实际 CPU、内存及现有加速设备，再确定评估规模。按几百条 episode、每次局部候选与几十道题的数量级，先预留 1–5 分钟 CPU 预算，实际时间以测量为准；新日志、源代码副本和评估表留在本研究 lab。无须付费模型调用、私有学生数据或云任务。

## 不确定性与实现审查重点

1. **心理解释不是答案的唯一成因。** 同一错答可能来自概念、程序、阅读、输入或偶发错误；错误程序是预测工具，不能定义学生身份。把方法证据、答案验证与自报信心分开。
2. **闭世界模拟很容易自我证明。** 规则生成器与规则识别器共享公式时，高分主要表明内部一致。必须加入未建模策略、相同答案碰撞和独立手写反例；现实有效性仍未验证。
3. **数据规模与题目覆盖不同。** S6 大量解释来自少量题；不能用响应数掩盖结构泛化不足。S7 的追问流程没有学习试验，这一限制应随报告进入实现说明。
4. **学习有变化，标签也应可撤回。** S5 支持跟踪变化，但不规定当前产品的撤回阈值。本次错误反证、后续矛盾与规则版本变化都应保留历史并重开检查，而不是覆盖旧事实。
5. **题目不够好时，选题算法无法创造信息。** 优先审查每组候选是否存在可用区分题、是否依赖未教前置知识以及是否存在非目标捷径；对同一模板的数值变体不称远迁移。
6. **全局 383 技能的联合推断并无证据支撑。** 局部 episode 可以复用技能关联，但不要枚举整个技能组合。S8 只验证有限规模和特定模拟模型，也不证明剪枝适合当前小规则库。
7. **既有产品边界必须保留。** 规则建议、数学验证和学习状态的写入权分开；重复有效解法不成为新学习步骤；owner 隔离、可取消响应、幂等事件、旧数据迁移及中英文同义状态均应验收。
