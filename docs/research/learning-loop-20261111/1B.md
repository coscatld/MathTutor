# 1B：数学学习闭环的学习与评估范式

检索日期：2026-11-11。范围：检索练习、间隔/交错练习、延迟保持、自我解释、近/远迁移及辅助暴露的评价边界。阅读了任务说明；未探索产品源码、未读取学生/账户数据、未进行模型训练或付费调用。以下是文献支持的设计建议及待检验假设，不是 MathTutor 已产生的学习成效。

## 核心结论

建议把一次“答对”改为一个可恢复的学习回合：**误概念假设 → 区分性诊断 → 纠错与自我解释 → 跨日独立提取 → 无方法提示的结构变化题**。每个阶段保留题目、时间、辅助暴露及验证来源；只有后两类证据能支持相应的保持/迁移判断。间隔和交错的单项技术有直接数学证据，但整套回合优于现有产品的结论仍需实验。

短时练习正确率不能作为唯一目标：微积分研究中，间隔条件练习成绩较低而期末成绩较高；高中 AI 辅导研究中，辅助状态成绩明显提高，移除辅助后的成绩却未必提高。[Lyle et al., 2022](https://link.springer.com/article/10.1007/s10648-022-09677-2)，[Bastani et al., 2025](https://doi.org/10.1073/pnas.2422633122)

## 从证据到功能的边界

1. **错误观察是待检验假设。** 单次错误可由误概念、计算失误、输入/解析问题或辅助依赖造成。建议挑选能区分候选解释的第二道题，并记录“支持/反证/仍不确定”。S5 展示程序迁移与概念分数可分离；“已会说为什么”不应直接消除误概念标签。[S5](https://cdn.vanderbilt.edu/vu-sub/wp-content/uploads/sites/280/2023/08/04183033/ATME_Rittle-Johnson_2006.pdf) 诊断辨别题的具体有效性仍须独立验证。
2. **复习是重新提取，暴露答案只是教学事件。** 先有学生自由作答，再提供适量提示与纠错。辅助后成功应保留为有价值的练习记录，独立提取成功另记。此区分直接服务于S7揭示的辅助成绩与独立成绩分离。[S7](https://doi.org/10.1073/pnas.2422633122)
3. **交错练习应要求学生自己选择方法。** 若题目前写着“本题用通分”，就减少了方法选择要求。先给初学者有限示例/同类练习，再逐步混合易混淆技能；不能用完全随机跨年级题流替代有课程约束的交错。直接数学证据来自S2/S3，成熟度阈值与混合比例属于产品实验参数。[S2](https://files.eric.ed.gov/fulltext/ED595322.pdf)，[S3](https://escholarship.org/uc/item/9429f5h9)
4. **保持、迁移与概念解释分别计量。** 同模板只换系数可标“新实例/同类保持”；同知识但改变表征、未知量或所需策略可标“近迁移”；跨情境且需自行识别方法可列“较远迁移候选”。远近不是一个通用二值标签，应登记变化维度与提示。S5与S6都不支持将一切新题统称远迁移。[S5](https://cdn.vanderbilt.edu/vu-sub/wp-content/uploads/sites/280/2023/08/04183033/ATME_Rittle-Johnson_2006.pdf)，[S6](https://doi.org/10.1037/a0019902)
5. **先实现可审计的保守时间规则。** 例如把跨日复习安排为候选1/3/7/14天，必须明确这是待调参数而非文献给出的最优间隔。S4支持跨周分布，不支持任意特定自适应公式。时间规则应容许错过后的恢复；错过复习不能自动当作答错或遗忘。[S4](https://link.springer.com/article/10.1007/s10648-022-09677-2)

## Tier 1：以可证伪误概念回合重构任务范式

**类别。** 把单题进度/技能分数串接改为一个跨会话、按证据转移的学习回合。现有任务说明已包含错误概念观察、独立迁移邀请及首次机会分母；创新工作应落在跨时任务控制及反证分支，不能只重命名这些字段。

**候选回合。**

```text
错误证据 -> 待辨别的误概念假设 -> 区分性探针
                                  | 证据不支持 -> 返回普通练习/待观察
                                  | 证据支持
                                  v
                       纠错 + 学生解释关键关系
                                  v
                       新实例的首次独立解答
                                  v
                          等待跨日提取
                                  v
                       跨日、无辅助提取探针
                                  v
                      混合题流中的结构变化探针
                                  v
                  已有延迟保持证据 / 已有指定迁移证据
```

任一阶段需要帮助时进入教学分支，保留原始首次机会结果并安排新探针；取消/离线/未到期只影响待办，不生成学习证据。结构变化探针失败可回到对应误概念假设，而不是机械重做整套流程。初步实现只覆盖少量本地验证器确实支持的技能族，不让生成式解释担任正确性裁判。

**可证伪假设。** 如果系统只有在“来源清楚的独立提取、真实跨日间隔、预定义结构变化”都获得相应证据后才推进回合，那么它会减少因提示、答案暴露、重复题及重放事件造成的虚假完成，并在真人的固定时间预算下提高28天后的无辅助结构迁移表现；理由是它将提取、时间分布和策略选择结合，同时避免把辅助完成当成习得。前半句是软件/测量假设；后半句是尚未证实的学习假设。[S2](https://files.eric.ed.gov/fulltext/ED595322.pdf)，[S4](https://link.springer.com/article/10.1007/s10648-022-09677-2)，[S5](https://cdn.vanderbilt.edu/vu-sub/wp-content/uploads/sites/280/2023/08/04183033/ATME_Rittle-Johnson_2006.pdf)，[S7](https://doi.org/10.1073/pnas.2422633122)

**为何是Tier 1。** 它改变任务的完成定义、诊断的反证路径、下一题选择和跨会话状态恢复，需要新的事件/状态契约与对照适配器。单独加复习提醒、调整间隔或加一句解释提示属于Tier 2。组成技术本身是成熟方法；本项目中的任务重构与整合效果仍具有不确定性，不声称科学上首次提出。

**先做的离线实验。** 对照应冻结当前提交与实际产品行为；不能凭文献想象基线。新策略和基线处理同一批人工可核验事件轨迹，seed=0。预先冻结至少六种轨迹类型：稳定误概念、偶发计算错误、提示依赖、答案已暴露、同题重复、独立成功后跨日失败；交叉正常/迟到/重放/取消事件及中英文输入。使用虚拟时钟模拟跨日，只验证时间逻辑。留出完整技能/题模板家族做开发外评估；仅换随机数的题目不能跨开发/评估集。不可把虚拟学生的“记忆状态”当观测真值来证明真人收益。

**离线判断标准（实施前锁定）。** 硬条件为零答案/选项暴露后的独立成功误记、零重复事件推进、零到期前的延迟保持认证、零未支持题目的数学认证、零跨用户证据混合；同时所有设计好的有效独立成功轨迹必须能推进、所有失败轨迹必须可回到练习，防止“永不完成”靠保守拒绝赢得分数。任何硬条件失败都阻止集成；通过后再比较到期覆盖、错误标签撤销、有效任务可达率和负担。阈值是本实验的工程验收标准，不能称为学习效应量。

**运行预算。** 此路线不训练模型；CPU上重放确定性事件和本地数学验证器即可。硬件与实际基线尚未由本子任务检查，父任务应在选定规模后测单轨迹时间再给总时长。这里不虚构GPU需求、吞吐或已完成的实验结果。

## Tier 2：Tier 1初测后的候选与消融

| 选项 | 具体变化 | 对照/消融与判读 |
|---|---|---|
| 固定间隔复习队列 | 少量跨日到期任务；独立作答后才增加间隔，辅助完成保留教学状态。 | 与T1比较只去掉诊断分支的版本；首先看状态正确性，真人延迟测验另评。候选间隔不宣称最优。[S4](https://link.springer.com/article/10.1007/s10648-022-09677-2) |
| 有课程约束的交错 | 在已教学、容易混淆且可验证的技能中交错；隐藏方法标签。 | 分块与交错使用同题库，记录时长；不要同时改变难度、反馈和题量而把结果全归因于交错。[S2](https://files.eric.ed.gov/fulltext/ED595322.pdf) |

## 可预注册的测量方案

### 离线指标：只说明系统行为

| 指标 | 操作定义/分母 | 不能据此推出 |
|---|---|---|
| 独立证据污染率 | 被错误计作独立成功的已暴露/已提示事件 ÷ 所有此类挑战事件；同时报原始计数。 | 学生记忆或迁移提高。 |
| 延迟认证错误率 | 未满足实际时间门槛却写入延迟证据的事件 ÷ 所有时间边界挑战。 | 虚拟时钟相当于真实遗忘。 |
| 有效推进可达率 | 满足预注册条件且系统能进入下一阶段的轨迹 ÷ 所有有效轨迹。 | 回合完成等于能力掌握。 |
| 诊断可撤销性 | 出现反证后按契约撤销/降级假设的轨迹比例，并报不确定/弃权覆盖。 | 标签准确率已在真人上验证。 |
| 复习服务覆盖 | 在给定虚拟日预算内得到机会的到期技能 ÷ 所有应提供机会的到期技能；另报实际逾期时长。 | 机会数等于学习收益。 |
| 数学可验证覆盖 | 本地验证通过的已支持题目、拒绝/不支持题目分别计数；对人工真值核验假接受和假拒绝。 | 自由文本或新题都已被可靠评判。 |
| 回放与取消一致性 | 重放同事件/取消回合后，状态与证据是否满足幂等和不推进契约。 | 任意真实使用场景都无缺陷。 |

单一加权“教学分”容易奖励保守不出题或过早结业，建议呈现硬门槛与上述分项，不以合成总分宣称胜出。

### 真人学习试验：须另行实施，当前没有数据

- **设计与目标人群：** 先选定一个年级和少量课程单元；在教师/年级块内随机分配班级至冻结基线与完整回合策略，避免同班互相透露不同辅导内容。预先固定题库蓝图、反馈资源、总学习时间预算与评测日期。主要估计整个策略包的效果，不能声称分离了间隔、解释和交错的因果贡献。
- **剂量公平：** 主分析采用相同可用时间、相同课程范围和题库难度蓝图；记录实际题量、独立尝试、提示和退出。不能同时假定“时间完全相等”与“完成题数完全相等”。若改用固定题数，应把时间成本作为预注册结果。
- **唯一主要结局：** 干预结束后28天（允许预定±3天窗口）的**无辅助结构迁移测验总分**；采用从未展示的题目，改变事先定义的表征/未知量/策略选择维度，隐藏方法标签，以固定盲评量规评分。该结局只支持所测维度的迁移，不泛化为全面远迁移。
- **次要结局：** 7天和28天同类新实例保持；即时测验；无提示策略选择；概念解释质量；到期复习出席、提示使用、实际学习分钟、挫败/退出。用预先规定的多重比较方案；不要挑显著的某个时间点作主结论。
- **首次机会与缺失：** 每题首次作答一经提交就冻结；提供了题目的未答/跳过按预设规则计分，不能从正确率分母消失。未参加整个延迟测验属于缺失结果，与答错不同；主分析遵循随机分组，登记缺失机制、插补/加权假设及敏感性分析。另报每组被邀请、出席、完成与有效评分人数。
- **统计：** 根据班级随机化使用聚类/分层模型，预设基线成绩与年级协变量，报告组间分数差、标准化效应和95%区间。用教育上最小有意义差异及保守班级内相关做事前功效模拟；不直接搬用S2的d=.83，也不把S3的系数SE当成Hedges’ g的SE。
- **可重复性：** 冻结协议、题目家族划分、评分量规、事件定义、分析程序和seed=0；在查看组间结果前确定停止规则、排除项和缺失处理。对新解释题抽样双人评分并报告一致性。真人参与所需的学校/监护人和研究数据安排须在该试验开始前另行完成；此离线研发不接触私人数据。

## 防泄露、辅助与测量反应控制

1. **开发/评估分离到题目家族。** 题干换数、变量改名、答案重排不是新家族。保存模板和结构签名，评测库不可进入提示示例、知识检索、复习推荐或反馈缓存。
2. **保留答案暴露事实。** 区分无辅助、方法提示、步骤提示、选项、完整答案、先前看过同题；任何一种已暴露状态都不能通过刷新、重开或切换语言恢复为“首次独立”。不要求删掉教学帮助，只要求诚实记录其证据等级。
3. **评测时隔离帮助。** 独立测验应暂时没有AI、提示、笔记、题库答案等资源；若允许计算器，所有组规则一致。若学生转入帮助模式，保存转入前结果并将后续记为辅助练习，而不是无辅助成功。
4. **方法线索也算线索。** 页面技能标题、上一题方法、选择题选项、AI追问可能暴露策略。无提示迁移测验隐藏方法分类；有提示迁移单独报告。S6的跨领域效果包含相关概念线索，故不能据此跳过这一区分。[S6](https://doi.org/10.1037/a0019902)
5. **控制测验本身的教学作用。** 7天测验会给28天结局额外检索机会；使用平衡的独立题目/技能子集或预设有无7天测验子组，避免将重复测验本身造成的保持误算为策略效果。不给后续主要结局所用题目提前反馈。
6. **固定观察窗口。** 主要后测从干预结束日计算，不按各学生最近成功日期动态平移；同时记录每个技能最后接触、最后提示、最后答案暴露与实际延迟。外部练习作为额外暴露记录，避免将复习量差异隐藏。
7. **避免诊断真值循环。** 模型判定的“误概念已修正”不能同时用作诊断标签和成功标准；用独立题目、可核验程序行为及盲评。语法无法解析应标不确定，不能计为概念错误。离线人工轨迹的标签只适用于所构造的场景。
