# MathTutor 0.6.3 发布说明

## 保存原题，围绕学生的困惑辅导

高中模式下，粘贴数学题进入 Agent 对话辅导。本地会话数据库保存原题、图片引用、当前疑问与最近讨论，刷新和重启后继续；顶部“当前题目”可展开查看。

模型自主选择知识联系、苏格拉底式追问、逐步解释、反例与配图。学生说“我看不懂”“为什么要这样”“这是怎么想到的”时先回应具体疑点；不能因为本地求解器不支持高中综合题就自动换成低年级方程。无需学生替模型编写教学提示词。

## 核验与学习证据

常规核验范围移至回复正文后的折叠说明，实际算式反驳保持醒目。修复函数记号、不同分支和端点条件被当成同一个方程比较的误报。加粗结尾和单侧极限符号不会误报回复未完成，真正缺运算数的公式仍保留未完成状态。

自由辅导记录是讨论笔记，不是独立完成或掌握证据。显式题库和可核验练习仍使用原有判题、答案披露与独立／受助／答案后作答记账。DKT 继续影子运行，不显示目标题掌握概率、不决定教学。

## 能力边界与试学

本轮用三道真实高中函数题和自然学生追问试学，覆盖参数范围、奇函数零点、分段定义域和保存原题后的作图。真实模型仍可能过度概括方法或给图形添加错误标注；可计算的图形不等于模型提供的图形定义和综合推理全部正确。没有真实学生学习效果结论。研究依据和限制见 [高中辅导改进记录](HIGH_SCHOOL_TUTOR_AUDIT_20261016.md)。

未连接模型时仍可使用原有本地练习与模板路径，自主高中辅导需要配置可用模型。API 密钥及个人数据库不随安装包分发。

## 安装

关闭旧版 MathTutor，运行 `MathTutor-0.6.3-win-x64.exe`。保留现有用户数据，数据库 migration head 仍为 024，无新增结构迁移。本次 Windows 包未进行 Authenticode 签名。macOS 未在本轮重新打包。
