## 本次纳入的改动

- 结构化教学计划、语言意图识别、困惑程度与支持策略；当前模型服务负责语义理解，后端保留数学验证和教学权限。
- 同知识点上下文、父子题焦点、独立练习推荐、作答与表达分离恢复、帮助呈现确认和答案暴露证据。
- 细粒度技能图谱、学习事件与 shadow 模式知识追踪；不把合成数据评估声明为真实学习效果。
- 前端教学状态与动作展示、数据导出及删除链同步。
- 统一版本号，并修正打包自检中的旧状态机断言与同答案练习测试样例。

详细验收覆盖与未完成项见 [Tutor v2 覆盖矩阵](../tutor-v2-coverage.md)。

## 构建方式

先在 web 目录执行 `npm run build`；再在 desktop 目录设置
`MATHTUTOR_PYTHON_RUNTIME` 指向项目已有的 `.runtime/python-mac-arm64-023`，执行
`npm run package:mac:unsigned`。该目录名是复用的 Python 运行时，不是应用版本。
最后串行执行 `npm run smoke:packaged:mac` 与
`node scripts/run-macos-no-api-key-smoke.js`，避免同一 DMG 的挂载冲突。
