# MathTutor 0.3.1

构建日期：2026-09-12。目标：macOS Apple Silicon / arm64。

## 改动

- 聊天支持截图粘贴、选择图片和拖拽图片；统一预览、移除、放大与校验。
- 支持纯图片和图文发送，每条最多 4 张 PNG/JPEG/WebP，每张最大 10 MiB；失败保留草稿并支持重试。
- 接入 OpenAI 视觉消息与 Ollama 原生图片格式，按模型能力拒绝不支持的请求。
- 图片及消息附件引用持久化到本机 SQLite；数据库迁移升级到 015，历史图片可恢复。
- 同步 Python、Web、Electron 与锁文件版本为 0.3.1。

逐文件实现与验收边界见 [图片附件交付报告](../chat-image-attachments.md)。
