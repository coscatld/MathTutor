# MathTutor 插件开发者指南

适用于 **MathTutor——基于学习过程追踪与可验证解题的开源数学智能辅导系统 0.7.0**。当前为试用版，具体安装包状态见 [README](../README.md#版本与发布状态)。

本文主要说明三类声明式教学插件。需要编写 Python / TypeScript 算法并通过 `/命令` 使用时，先读[代码插件开发说明](CODE_PLUGINS.md)。本文面向编写和发布插件的开发者。普通用户只需在社区“我的插件”点击“导入插件”，选择已下载的 `.mathtutor` / `.mtplugin` 文件；不需要 Python、命令行或手写清单。开发者使用本文的清单示例和离线打包工具创建插件，生成文件后在社区导入调试。

## 1. 选择合适的扩展方式

| 方式 | 可以做什么 | 谁安装与执行 | 当前边界 |
| --- | --- | --- | --- |
| 社区声明式教学插件 | 配置智能组卷、错题复盘、学情可视化，附上作者教学指导 | 普通用户导入数据包；应用内置工作流执行 | 不能新增任意算法、执行代码、联网、读写系统文件或修改学习事实 |
| 社区代码插件 | 开发者提供 Python / TypeScript 函数，用户通过斜杠命令调用 | 用户导入单文件或受限 ZIP，明确同意本地代码后启用 | 按本机账户权限运行，不是操作系统沙盒；无自动依赖安装 |
| 可信 Python SDK | 编写真实工具处理器，注册类型化参数、结果与教学技能 | 应用开发者审核代码，在可信服务启动时注册 | 代码运行于应用进程，**不是沙盒**；接口仅在开发文档中提供，不能作为普通社区数据包装进应用执行 |

如果需求是“高三每周八题”“先回顾条件的错题复盘”“每十次独立作答的趋势”，使用社区插件。如果需求是新计算器、外部系统适配或新增桌面执行能力，可以使用[代码插件](CODE_PLUGINS.md)，或在自己的可信应用构建中使用 [Python SDK](CREATOR_EXTENSIONS.md)。把 Python、JavaScript 或 `SKILL.md` 放进资料库不会注册工具。

社区教学指导属于作者参考内容，不是系统指令；不能覆盖学生当前问题、修改答案披露规则、授予目录权限或要求宿主绕过预算。

## 2. 准备开发目录

需要 Python **3.11–3.13**，并在 MathTutor 仓库根目录安装开发依赖：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
```

Windows PowerShell 的激活命令为 `.venv\Scripts\Activate.ps1`。这些依赖用于开发与测试，普通用户使用桌面安装包时不需要配置它们。

建议将自己的插件单独维护：

```text
my-teaching-plugin/
  plugin.json                 # 开发清单，不含学生数据或密钥
  README.md                   # 面向使用者的说明
  CHANGELOG.md                # 每次版本修改
  LICENSE                     # 你有权授予的许可证
  dist/
    my-teaching-1.0.0.mathtutor # 校验后生成的分享文件
```

从 [三个完整模板](../examples/community-plugins/) 复制一个最接近的工作流。先将 `id` 改为自己的唯一前缀，如 `example.grade12-weekly`，并填写真实作者信息；不要使用 `mathtutor.*` 冒充项目示例。共享目录中相同 ID 与版本的内容不可被另一个包悄悄替换。

## 3. 写第一份插件清单

下面是完整可用的“高三每周练习”开发清单，保存为 `plugin.json`：

```json
{
  "schema_version": "mathtutor.community-plugin.v1",
  "kind": "teaching-plugin",
  "id": "example.grade12-weekly",
  "version": "1.0.0",
  "name": "高三每周练习",
  "description": "按知识点均衡选取八道高三练习，先独立尝试再核对答案。",
  "author": "示例开发者",
  "license": "Apache-2.0",
  "tags": ["高三", "每周练习"],
  "grades": [12],
  "readme": "在组卷设置中选择范围，生成后先独立作答。可以保存试卷，参考解析供核对。",
  "changelog": "1.0.0：首次发布。",
  "workflow": "exam-builder",
  "defaults": {
    "grade": 12,
    "question_count": 8,
    "seed": 42,
    "point_codes": [],
    "include_answers": false,
    "focus_weak_skills": false
  },
  "teaching_guidance": "先请学生说明题目条件及方法选择，再根据其当前问题提供提示。",
  "required_permissions": ["question_bank"]
}
```

`grades` 是资源发现时的适用年级标签，`defaults.grade` 才控制实际组卷年级；两者不会互相推导。缺省配置会补齐为宿主默认值；数字和布尔值必须使用真实 JSON 类型，不能把 `12` 写成 `"12"` 或将 `true` 写成 `"true"`。未知字段、重复 JSON 键、非有限数值和超范围配置均应在发布前解决。

### 清单字段

| 字段 | 约束与含义 |
| --- | --- |
| `schema_version` | 固定 `mathtutor.community-plugin.v1` |
| `kind` | 固定 `teaching-plugin` |
| `id` | 3–80 字符；小写字母开头，后续仅小写字母、数字、`_`、`.`、`-`；升级时保持稳定 |
| `version` | 三段非负整数，每段 0–9999；如 `0.1.0`、`1.0.1`。不接受 `01.0.0`、`1.0`、`v1.0.0` 或预发布后缀 |
| `name` / `author` / `description` | 分别最多 80 / 120 / 500 字符，不能空白 |
| `license` | 1–80 字符，仅字母、数字、`.`、`+`、`-`；优先使用适合内容的 SPDX 标识。字段不是对你拥有版权的自动证明 |
| `tags` | 最多 12 个非空短标签，每个最多 32 字符 |
| `grades` | 最多 12 个不重复的整数，范围 1–12；10、11、12 分别表示高一、高二、高三 |
| `readme` / `changelog` | 必须有正文，分别最多 12000 / 8000 字符；清楚说明使用、变更与结果边界 |
| `workflow` | `exam-builder`、`mistake-review`、`learning-report` 三选一 |
| `defaults` | 对应工作流的有界配置，见下一节；不接受其他工作流字段 |
| `teaching_guidance` | 最多 2000 字符，指导如何解释与组织结果；不授予新权限、不替代用户当前要求 |
| `required_permissions` | 无重复项；只支持 `question_bank` 与 `read_learning_records`，且必须符合工作流用途 |

裸插件清单最大 **64 KiB**；长中文正文也计入 UTF-8 字节限制。分享封套中的资源元数据由打包工具生成，不应手工写入 owner、启用状态、用户同意记录、模型密钥或学生报告。

## 4. 三个工作流的全部配置

### 智能组卷 `exam-builder`

| 参数 | 类型、范围 | 默认值 | 用途 |
| --- | --- | --- | --- |
| `grade` | 整数 1–12 | `10` | 选择实际课程年级 |
| `question_count` | 整数 1–20 | `8` | 目标题数；候选不足时如实返回较少题目 |
| `seed` | 整数 0–2147483647 | `42` | 固定抽题顺序；相同题库、范围和种子可复现选题 |
| `point_codes` | 最多 16 个编码；每个仅小写字母、数字、`-`，长 1–80 | `[]` | 精确限定知识点；空列表表示不额外限定 |
| `include_answers` | 布尔值 | `true` | 是否在结果中附参考答案与解析 |
| `focus_weak_skills` | 布尔值 | `false` | 优先有真实错误证据且能映射到现有技能图的知识点 |

基础权限为 `question_bank`。如果启用薄弱技能优先，清单还必须声明、用户还必须同意 `read_learning_records`。仅声明权限不会自动读取记录；仅改 `focus_weak_skills` 也不能绕过授权。

题目来自应用实际课程参考题库。知识点编码可在题库中查询，或通过开发 API `GET /api/v2/math-tutor/desktop/exercise-bank` 和对应知识点详情查看；错误或无候选编码不会生成虚构题目。参考答案不是学生步骤核验结果，输出中的 `student_steps_auto_verified` 保持 `false`。

### 错题复盘 `mistake-review`

| 参数 | 类型、范围 | 默认值 | 用途 |
| --- | --- | --- | --- |
| `limit` | 整数 1–30 | `12` | 最多复盘条数 |
| `include_assisted` | 布尔值 | `true` | 是否纳入受助或看解答后的真实判定，并保留类别 |
| `include_partial` | 布尔值 | `true` | 是否纳入部分正确的作答 |

权限必须为 `read_learning_records`。只使用当前用户有效、未被排除的真实错误或部分正确记录；原题或学生步骤缺失时明确标记。没有记录就返回空清单，不推测学生错在哪里。

### 学情可视化 `learning-report`

| 参数 | 类型、范围 | 默认值 | 用途 |
| --- | --- | --- | --- |
| `window_size` | 整数 5–100 | `10` | 每个趋势窗口包含的独立整题观察数 |
| `max_events` | 整数 10–1000 | `500` | 最多读取的近期有效事件数 |

权限必须为 `read_learning_records`。趋势正确率为：

```text
窗口正确率 = 该窗口独立整题正确观察数 / 该窗口独立整题观察数
```

重复、排除、不确定与非独立整题观察不能抬高独立正确率；自我报告、提示后和看答案后作答分别计数。空记录返回空序列与 `null` 准确率，不补零分或满分。它不是 DKT 预测、知识掌握率或标准化测验成绩。

## 5. 权限、启用与真实数据

`required_permissions` 声明“此插件可能需要哪些数据”，用户同意并启用才允许实际调用。新安装默认停用，同包重复导入保持原状态；升级保留个人配置并重新停用，新增权限不会自动获得同意。每个用户单独安装、配置和授权，卸载或停用阻止后续调用。

三个工作流只读题库或用户学习记录，不写学生作答、学习事件、掌握事实、DKT 观察、练习发布状态或系统文件，不调用付费模型。作者不能在指导中要求把报告伪装成学习证据。

社区源只提供资源数据，不接收学生记录。页面运行在本地服务完成；只有用户在当前对话中实际调用插件工具，应用才会把有界结果交给所配置的对话模型。若使用云模型，题目或记录片段可能进入该模型请求；不要在说明中承诺“所有插件结果永不出本机”。

插件安装和启用设置独立保存，不属于现有 SQLite 备份。导出分享包不包含用户同意状态或报告。正常重启保留插件选择；成功恢复数据库后插件停用并清除数据同意，需重新启用。文件目录授权另行管理，重启失效，社区插件不能申请该权限。

## 6. 校验并生成分享文件

在 MathTutor 仓库根目录运行：

```bash
python examples/community-plugins/build_bundle.py /path/to/my-teaching-plugin/plugin.json \
  --output /path/to/my-teaching-plugin/dist/my-teaching-1.0.0.mathtutor
```

先创建 `dist` 目录。输出也可以使用 `.mtplugin` 后缀。这两个后缀是便于用户识别的分享文件名，文件内容均为 **UTF-8 JSON**，不是 ZIP、可执行文件或代码安装器。

打包工具会：

1. 拒绝超大、重复键和非有限数值的清单，调用应用相同的严格校验器。
2. 补齐有界默认值，对规范化插件内容生成 SHA-256。
3. 生成 `mathtutor.community-resource.v1` 封套，再用真实资源 schema 校验。
4. 独占创建新文件，打印分享文件及插件内容两层 SHA-256；不联网、不安装、不启用，也不覆盖已有输出。

两层哈希用途不同：`Bundle SHA-256` 校验整个下载文件，封套内 `package_sha256` 校验规范化插件内容。规范化使用 UTF-8、键排序、紧凑分隔符、禁止 NaN；不要手工将漂亮打印后的原始字节哈希混入内联插件封套。哈希证明内容一致，不能证明作者可信或教学质量。

如果文件已经存在，选择新的输出名，或由开发者明确删除旧文件后重建。修改已公开的内容必须先提升插件版本号。

## 7. 本地调试与回归

先启动源码应用或使用对应试用版桌面包，在社区点击“导入文件”，选择生成文件，检查作者、说明、权限和配置。明确同意后启用，运行并保存结果。分别检查：

- 组卷在相同范围和顺序设置下是否复现；关闭答案后是否只返回题目；候选不足是否如实说明。
- 新账户没有学习记录时，错题和趋势是否为空；带真实记录时能否回到相应题目与作答类别。
- 未启用、未同意权限、跨用户、停用、卸载后是否拒绝调用；升级是否保留个人配置并重新停用。
- 用户看到的说明是否清楚，是否把参考答案或练习正确率误写成自动核验或掌握度。

开发者可直接调用校验接口，不产生安装副作用：

```text
POST /api/v2/math-tutor/desktop/community/plugins/validate
body: {"package": <裸插件清单对象>}
response: {"package": <规范化清单>, "package_hash": "..."}
```

所有管理接口使用现有用户认证；变更操作还检查本地 Origin。插件专用导入使用 `POST /api/v2/math-tutor/desktop/community/plugins/import`，以 multipart 的 `file` 字段上传插件文件；资料专用导入是 `POST /api/v2/math-tutor/desktop/community/documents/import`，以重复的 `files` 字段提交文本及相对文件名。两者可附 `operation_id`，并在写入前拒绝错误类型；原 `/community/import` 兼容接口仍保留。校验接口不启用插件；导入也不代替逐项同意。完整启停与配置 API 见[插件格式说明](COMMUNITY_PLUGINS.md#管理-api-与结果)。

仓库离线回归：

```bash
python -m pytest tests/test_plugin_bundle_cli.py tests/test_community_plugins.py \
  tests/test_community_plugins_api.py tests/test_community_resources.py -q
```

打包互通测试使用真实校验器、社区文件导入与 owner 插件存储；工作流测试使用真实题库和受控学习记录。模型传输桩仅验证工具集成，不代表在线教学质量，整个流程无需模型密钥或付费调用。不要把为调试编造的数据或旧评测成绩当成本版真实质量证据。

## 8. 升级与兼容

首次发布可用 `1.0.0`，修复后用 `1.0.1`；三段均不得带前导零。相同 ID 的新内容必须使用更高版本，降级或同版本换内容会被拒绝。同一 ID 不可更换工作流，需要改工作流时创建新 ID。

升级保留用户已有配置，不用新的 `defaults` 覆盖个人选择；即使默认参数变化，也应在更新说明中写清楚。新增数据权限需在清单中声明，升级后让用户重新阅读并明确启用。发布后不要修改既有版本的下载内容或目录元数据，应发布新版本并保留旧文件。

## 9. 发布到 GitHub 或自定义资源源

最简单的分享方法是将 `.mathtutor` / `.mtplugin` 文件作为仓库文件、发行附件或自己的 HTTPS 下载附件发布。使用者下载后在社区“一次导入”，再检查权限并启用；不需要手工编辑文件。

开发者集成如需读取目录，可以发布一个 `catalog.json`，或直接发布单资源封套。GitHub 可使用原始文件地址，例如：

```text
https://raw.githubusercontent.com/YOUR_ACCOUNT/YOUR_REPO/main/catalog.json
```

这里的账户、仓库和路径需要替换为自己的真实地址。普通用户下载生成的文件后导入。若开发者要构建自己的目录集成，可调用下面的已认证本地 API；常规社区页面仅提供个人资料导入与已装插件管理。

开发者目录 API（均在 `/api/v2/math-tutor/desktop/community` 下）：

```text
POST /sources                  {"name": "目录名称", "url": "公开HTTPS原始文件地址"}
POST /sources/{source_id}/refresh
GET  /catalog
```

这些接口沿用当前用户认证，变更操作检查本地 Origin；刷新只缓存资源元数据，不自动安装、启用或接收学生记录。开发者负责为自己的集成设计明确的用户选择流程。

包含单个插件的目录结构为：

```json
{
  "format": "mathtutor.community-catalog.v1",
  "name": "我的教学插件",
  "resources": [
    {"metadata": "替换为分享封套中完整的 resource.metadata 对象",
     "package": "替换为分享封套中完整的 resource.package 对象"}
  ]
}
```

上面仅解释结构，两个字符串必须替换为真实对象。可以在开发脚本中读取已生成文件，将 `bundle["resource"]` 原样放入 `resources`，避免重算或抄错哈希。一个目录最多 100 个资源版本、8 MiB；离线分享文件最多 32 MiB，单个插件仍受 64 KiB 清单限制。

自定义源必须使用公开 HTTPS；不接受本机、私网、带凭据或令牌参数的地址。默认无重定向、无账户 Cookie，不支持私有仓库登录或依赖作者机器上的路径。远程包引用的 `download_url` 必须与目录同源；只在用户明确导入时下载并校验。内联 `package.data` 对小插件最简单，避免额外远程包请求。

源目录可在资源 metadata 中附公开 `project_url`、`issues_url`、`discussions_url`，帮助使用者回到源码、报告问题或讨论；这些是分享封套的资源元数据，不是裸插件清单字段。若手工添加，须再次用 `CommunityService` 解析验证，不要绕过严格字段校验。项目自身的问题与提议可到 [MathTutor Issues](https://github.com/coscatld/MathTutor/issues)；你自己的仓库应提供实际可用的协作入口，未开启 Discussions 时不要承诺该入口可用。

发布说明至少包含版本、作者和许可证、支持的工作流与数据权限、试用步骤、真实结果边界、兼容版本和问题反馈方式。不要附带模型密钥、认证 Cookie、个人学习记录或绝对本机路径。

## 10. 常见错误排查

| 现象 | 检查方法 |
| --- | --- |
| 提示格式、版本或配置无效 | 检查未知字段、真实整数/布尔类型、版本前导零、全空白元数据、重复年级和权限；先运行离线打包或 `/validate` |
| 清单能校验，但分享包导入校验失败 | 从规范化清单重新打包；不要改封套里的内容却保留旧 `package_sha256` |
| 提示同版本已有不同内容 | 使用自己的 ID，提升版本并重新打包；不要修改已有公开版本或复用 `mathtutor.*` 示例 ID |
| 安装后运行不了 | 新装和升级均可能停用；查看当前用户是否逐项同意必要权限并明确启用 |
| 薄弱技能优先开启失败 | `exam-builder` 清单是否声明 `read_learning_records`，当前用户是否同意；不支持的技能保持未知 |
| 没有错题或折线 | 查看是否确有当前用户有效的独立作答或错误判定；聊天自述、重复或被排除记录不能制造统计 |
| 升级后默认参数没有覆盖旧设置 | 这是保留个人配置的行为；在插件配置里明确修改，不在升级时强行重置 |
| 远程目录刷新失败 | 使用真实公开 HTTPS 原始文件地址，检查网络、内容类型和大小；远程包须同源，不能依赖登录或重定向 |
| 打包提示输出已存在 | 换新文件名；工具不会覆盖现有文件或跟随其符号链接 |
| 想加入网络、文件或自定义算法 | 使用独立的[代码插件格式](CODE_PLUGINS.md)，或可信 SDK；声明式格式仍只组合内置工作流 |

需要新增 SDK 工具时，请继续阅读[创作者扩展接口](CREATOR_EXTENSIONS.md)。其中的 `ExtensionRegistry`、`ExecutionContext`、严格参数模型、注册与撤销生命周期及目录工具示例均可离线测试；勿将可信处理器伪装成普通用户可安全安装的任意代码包。
