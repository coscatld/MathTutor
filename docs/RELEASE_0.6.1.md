# MathTutor 0.6.1 发布说明

修复 Windows 0.6.0 首次并发启动可能造成的数据库迁移异常，以及之后只显示“本地辅导服务在 60 秒内未就绪”的问题。数据库版本仍为 024。

- 桌面程序只保留一个实例；重复打开会显示已有窗口。
- 对同一个数据库的迁移使用进程锁，SQLite 表结构与版本更新在一个事务中提交。进程异常退出后操作系统会释放锁。
- 对已出现的 `023 + 024` 版本记录，先创建并校验备份，再检查当前数据库的表、列、主键、外键及完整性。全部通过后只移除冗余的 023 记录，学习内容保持原样。结构不符或出现其他异常版本时停止恢复并保留原库。
- 启动日志保存在 `%APPDATA%\math-tutor-desktop\logs\startup.log`，上一次日志为 `startup.previous.log`。后台进程退出或启动失败会显示具体错误与日志位置。

## 从 0.6.0 更新

1. 关闭旧版 MathTutor 及其错误窗口。
2. 运行 `MathTutor-0.6.1-win-x64.exe` 安装新版，可继续使用中文目录。
3. 启动软件。符合上述已知异常的数据库会自动备份并恢复，无需删除 `%APPDATA%\math-tutor-desktop` 或重新安装 Python、Node、Conda。

迁移前备份位于用户数据目录 `backups` 下，名称包含 `pre-024` 和时间。已有系统凭据存储时备份按产品策略加密，恢复密钥由软件管理。若提示结构校验失败，请保留原数据和启动日志以便进一步诊断。

Windows x64 安装包未签名，随包提供 blockmap 和 SHA-256 校验文件。Windows 实包验收及源码测试结果以此次发布对应的 GitHub Actions 记录为准。
