# MathTutor 0.6.5 发布说明

## 学习支持界面

重新设计教学提示、对话资料和知识库与问答范围。教学目标、可用帮助、资料处理状态与当前会话检索范围分组展示；删除顶栏重复的“收起”按钮，保留工具切换、面板关闭与 Escape，关闭后恢复键盘焦点。窄屏与横屏保留输入空间，范围未保存时提示离开确认。

学习记忆展示实际正文、来源、确认状态和启用开关；文档就绪、处理失败、扫描件与停用状态分开标记。界面预览见[设计与验收记录](../design-system/mathtutor/pages/learning-support.md)。

## 学习记忆实际参与回答

修复普通聊天没有读取记忆、结构化辅导组装后丢弃记忆的问题。两类模型回答现在使用同一份遵守用户隔离、开关与删除状态的只读上下文，按最近修改顺序、完整记录和固定预算选入。未确认的 AI 推测不参与回答；当前问题、语言、格式及提示请求优先。

记忆不增加掌握度、独立作答证据或答案披露权限。停用、修改、删除在下一轮读取时生效；聊天历史本身不会因此被删除。离线基础模板不解释任意文字偏好。真实 API、SQLite、重启与模型输入捕获证据见[记忆链路检查](LEARNING_MEMORY_AUDIT_20261016.md)。

## 十二年级课程题库

按用户课程范围补齐 **383 个知识点、801 道原创课程参考题**，另有 **353 道本地步骤核验练习**，共 **1,154 道题**。新增半时、元角分、公因数公倍数、工程与追及、几何证明、函数值域、导数参数与零点、递推与求和、圆锥曲线定点定值和统计推断等实题；修正不相符的练习映射和运算模板。

支持按学段、年级和知识点查看，跨年课程可在适用年级查到。课程参考答案默认隐藏，题干、参考答案和解题说明独立保存；“请 Tutor 讲解”只发送题干。参考证明与高级课程题不标成学生过程已被自动验证。数量、逐知识点覆盖和数学复核见[题库报告](QUESTION_BANK_COVERAGE.md)。

## 安装与验收

- Windows x64：关闭旧版后运行 `MathTutor-0.6.5-win-x64.exe`。
- macOS Apple Silicon（M 系列）：打开 `MathTutor-0.6.5-mac-arm64.dmg`，将应用拖入 Applications 后启动。本次不提供 Intel Mac 安装包。
- 数据库 migration head 保持 **024**，没有新增结构迁移；保留现有学习数据。安装包包含独立 Python 与前端运行时，不需要用户另装 Python、Node.js 或开发环境。
- Windows 包未进行 Authenticode 签名；Mac 包未进行 Developer ID 签名或 Apple 公证。

打包前的源码回归为后端 2760 通过 / 11 跳过、前端 217 通过，生产构建与三套真实浏览器检查通过。发布附件中的构建身份、SHA-256、三平台 CI、实际安装启动及只读 DMG 验收记录对应本版提交，不能用旧安装包的验收替代。本轮没有新增付费模型调用，没有修改历史基准答案、分数或图表，也不宣称此次更新已经提高基准成绩。
