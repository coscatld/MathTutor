# 003：整题错误观察的页面闭环

本轮在已有学习画像中增加“整题错误观察”区，直接消费后端item_error_observations。显示具体技能待定位及“该题后来答对，技能仍待独立检验”，不展示虚构的技能弱项或掌握百分比。默认折叠明细，按整题cycle调用已有学习依据抽屉；不修改原作答记录。旧后端没有该字段时不生成空错误区。

类型同步到StudentSummary和StudentExport，新增字段可选。前端252项单元/组件测试通过；生产构建16路由通过。生产构建用于隔离本地Chrome检查，API请求使用明确标识的合成夹具，不涉及个人数据库，不能作为真实学生教学效果或生产API测试。

实际浏览器检查：

- 原画像/复盘/推荐/资料范围等既有流程，1280×800、1024×768、375×812、812×375。
- 新整题观察区额外检查浅/深色×1280、375、812宽度共6组，启用减少动画。
- 折叠展开、未定位/后续纠正文案、按cycle_id而不是skill_id请求记录、关闭对话框后焦点回到原按钮。
- 无横向溢出、无页面运行异常，按钮实际触控区域至少44×44像素。
- 首次检查发现复用mt-btn默认高度40px未达新按钮44px目标；补min-h-11后通过。视觉复核发现手机左右并排会挤压文案，改为小屏上下排列后重新构建并跑完整浏览器检查通过。
