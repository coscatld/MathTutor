## 2. 实际行为变化

### 备份与恢复前检查

`BackupManifest.from_dict` 对 `backup_path`、`created_at`、`sha256` 要求字符串，异常清单沿用“不可读”状态和文件时间回退，不再让列表失败。保留策略不把孤儿清单算作备份，保留“最近 N 个实际备份”与“最近 N 个清单可读且大小匹配候选”的并集；正常情况下仍为 N，近期异常时最多 2N。超过两组集合的旧异常文件照常轮转。

`status=ok` 仅表示元数据与大小检查通过，不表示已通过散列或数据库完整性检查。恢复前的原有校验保持不变。设置页解释异常情况下数量可能超过设定值。

### 学习画像与资料定位

学习画像记录可核验的表现，并提供下一次练习入口。独立整题资格沿用既有 `independent_target`：选择作答、局部步骤、诊断和错因分析不增加首次独立自由作答证据；来源或结果未知进入未判定；受助与看过答案后作答分开；同题重试不重复增加首次独立证据。原始事件、排除记录、训练标签和多技能联合归因保持原规则。

页面按“下一步 → 实际观察 → 阶段复盘”排列，覆盖数量明确不是掌握率，缺失计数显示“待确认”。偏好折叠，抽屉和焦点恢复保留。复盘加载不再提前显示空状态，刷新成功后清除旧错误。

知识库说明“保存资料 → 对话中选择并应用 → 回答引用时查看原文”，并能回到当前会话的资料选择器。导航本身不修改授权范围；上传/阅读资料不增加掌握证据。新建会话时保留面板和题库启动参数。检索内核没有重构。

### 社区组件开发与兼容

新增 `python -m mathtutor.extensions.developer init/build/check`。支持 Python 与 TypeScript 模板，要求作者填写许可；构建只包含入口与明确指定文件；检查复用正式导入校验器且不执行代码。已有目录和输出不覆盖，符号链接、越界路径、超限和哈希错误拒绝。旧打包脚本保留参数，转调公共实现。

从 CLI 生成的两种模板已通过真实社区服务导入、未授权拒绝、授权启用和实际解释器运行。代码结果保持参考信息，不能冒充数学核验或学习证据。插件仍按当前本机账户权限执行，进程限额不等同于操作系统沙盒。

新增 `adapt-harness`：将导出 `apply(ctx, config)` 并通过 `ctx.tools.register` 注册纯工具的 TypeScript 源码包装为原有代码插件包。显式选择工具，JSON 参数及输出按明确 schema 子集校验；未知服务/字段/关键字拒绝，构建时不执行作者源码。提供乘二示例。独立审查发现的入口名占位符替换和动态 schema 修改漏检均已修复并有真实进程回归。这是工具接口子集，不是整个 Cordis/Harness 生态兼容；详见插件验证记录与 `docs/CODE_PLUGINS.md`。

### 官网与产品 UI

官网新增三个按任务组织的入口：首次练习、读懂学习记录、参与开发。首页采用留白、纸面底色、蓝色重点与明确编号的学习流程，已有真实截图继续使用，不加入外部字体或动画依赖。去掉可能被误认为轮播的图片数量标记。

文档首页按“我现在想做什么”组织；重新解释对话、资料库、学习画像职责。正文增加章节间距、阅读行长、表格/代码可读性及锚点偏移，侧栏去除重复分组名称并展开常用指南。知识库和学习证据指南同步更新中英文内容；修复中英文安装和 FAQ 的 6 处既有断链。深色模式主按钮使用独立的前景色，避免浅蓝底白字低对比；交互动效遵守 reduced-motion。

源码变更已在本地导出检查，没有部署到公开 GitHub Pages，安装包也没有更新。

### RAG 固定样本专项评测

运行现有 `scripts/rag_hard_set_probe.py --evaluate` 的真实检索路径，临时数据库与内存密钥存储隔离，没有付费模型。为保留历史结果，仅将产物位置定向到本轮目录，脚本未改。完整指标和 provenance 在 [rag-evaluation-001.json](assets/rag-evaluation-001.json)。

- easy：9 queries / 12 chunks，R@5、MRR@5、nDCG@5、Hit@1 均为 1.000。
- hard：5 queries，R@5=1.000，MRR@5=0.900，nDCG@5=0.949，Hit@1=0.800。
- 块级上下文 precision=0.3444、recall=1.0000；关闭扩展时 precision=0.3500，提示当前扩展会引入一些干扰，不能据此说扩展改善质量。
- 无权限扩展泄漏，隔离检查通过；引用归因 P=0.875、R=1.000；回执校验和未授权拒绝为 1.000。
- 语义评测 `BLOCKED_PROVIDER`，faithfulness `NOT_MEASURED`。固定合成样本结果不代表真实学生效果，也不代表本轮检索内核有质量提升。
