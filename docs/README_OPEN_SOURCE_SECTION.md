## 开源参与与社区生态

MathTutor 采用 Apache-2.0 许可证，包含 Python/FastAPI 后端、Next.js/React 前端、Electron 桌面端，以及教学策略、数学核验、学习过程追踪与自动化评测代码。开发者可 Fork 仓库发起 Pull Request。

- [如何参与贡献](../CONTRIBUTING.md) · [开源仓库结构](OPEN_SOURCE_REPOSITORY_MAP.md) · [安全披露](../SECURITY.md)
- [题库格式与投稿](QUESTION_PACK_CONTRIBUTION.md) · [共享题库完整规范](SHARED_QUESTION_PACKS.md)
- [插件快速入门](PLUGIN_QUICKSTART.md) · [插件开发详细指南](PLUGIN_DEVELOPMENT.md)
- [声明式教学插件](../examples/community-plugins/) · [Python/TypeScript 插件](../examples/code-plugins/) · [题库示例](../examples/question-packs/)

目前社区产品界面主要支持用户主动导入个人文件、题库和下载的插件；它不是自动向所有用户分发未知第三方插件的托管商店。代码插件需要用户额外确认信任，而且目前不是 OS 沙盒。题库参考答案不自动成为已验证结论或学生掌握证据。
