# 中英文界面与语言偏好

日期：2026-10-28（Asia/Shanghai）。源码基线：`392e3bf656d0594ffab59d869edaa3e930542e96`。本记录对应待发布的界面改进，既有 0.7.1 下载资产保持其原构建内容。

## 使用入口

打开 **设置 → 通用 → 界面语言**，选择 **中文** 或 **English**。选择立即生效，无需点击模型配置的保存按钮。初次配置模型、初评、登录／注册及启动阻塞页面也有紧凑语言选择器，尚未进入工作区时仍可切换。

默认语言保持中文。偏好作为非敏感显示设置保存在本机，刷新页面和其他已打开窗口会使用同一选择。浏览器拒绝保存偏好时，当前会话仍可切换，并明确提示偏好没有保存。无效的存储值回退到中文，控件始终只有两个选项。

## 切换范围

导航、设置面板、模型配置表单、学习画像、练习、题库筛选、初评、资料、知识库、记忆、社区及图形控件均接入中文／英文界面文案；按钮、输入标签、读屏名称、确认对话框与提示状态一并处理。语言名称使用各自的原文，方便随时切回。

界面语言不改写题干、参考答案、笔记正文、用户标题与标签、历史作答、聊天内容或模型生成的自由文本，也不改变后端的命令、状态枚举、数学核验或学习证据。带用户数据的提示使用参数插值，参数原样显示，不递归翻译。

## 状态与持久化

- 全局 Context 更新文案，没有按语言重新挂载页面。模型密钥／模型名／服务地址草稿、知识库编辑 revision、已选初评答案及图形读数继续保留。
- 语言变化不会重新读取设置或笔记，也不会触发配置保存或额外模型请求。原有 CAS、operation ID、导航保护和作答绑定继续生效。
- 本地存储只写入 `mathtutor-language` 的 `zh-CN` 或 `en`。凭据、学习正文和其他用户数据没有进入这份偏好。
- 启动脚本校验语言值，React 使用一致的服务端快照完成 hydration，再恢复本机偏好；`html.lang` 随选择更新。跨窗口只监听语言键和存储清理事件，卸载时清除监听器。
- 翻译函数只读取词典自有的字符串属性，未知词条保留原文；`constructor`、`toString`、`__proto__` 等字符串不会触发继承属性读取或崩溃。
