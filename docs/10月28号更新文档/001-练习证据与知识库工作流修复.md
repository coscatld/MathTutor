# 练习证据、笔记保存与初评恢复

日期：2026-10-28（Asia/Shanghai）。源码基线：`eb5683cf221d5dcfb8d80904c1e7d6671b949a04`。本记录对应其后的开发改进，状态为待发布；正式下载仍对应 0.7.1 的既有构建。

## MT-TEACH-003：练习入口与证据口径一致

新建 A1（独立完成后的迁移）、A2（受助完成后的巩固）、B（看答案后的检测）邀请，在推荐快照保存 `response_mode=free_response` 和 `observation_kind=independent_transfer`。接受后先显示题干，输入框直接进入绑定本题的作答模式，响应中不携带选项。判题继续使用原来的精确发布快照和本地自由答案验证器。

“显示选项（转为诊断）”是学生主动选择的操作。系统先保存 `options_exposed` 事实，再返回选项；同一规范题目的暴露记录会随重启、不同对话与新周期保留。之后即使改用文字输入答案，也按诊断观察处理。已发生的首次自由作答不因后来查看选项而被改写。新的独立迁移仍需另一道未见新题。

旧邀请缺少新增字段时继续使用选择题诊断语义。C/D/E 等选择题模式继续可用，相关入口与观察目标明确显示为诊断或复习。选择题仍可参与既有离散难度规则，不会变成首次独立自由作答标签。

接受选择题邀请时，子周期、教学上下文与选项暴露事实在同一 SQLite 事务提交。注入暴露记录写入失败时，邀请保持未接受，不留下可读取的子题选项；重试成功后，跨周期重做仍不能绕过已暴露的事实。主动显示选项的中断采用保守记录，尚未确认显示成功也不会生成独立证据。

完成卡分别显示诊断选择答对、首次独立自由作答及其中整题答对、受助或答案后作答记录。原来无帮助选择答对后出现两个零的情况，现在会显示一条诊断正确，并给出下一步的新题建议。这些数值是已记录作答的分类，不是学习效果或能力定级。

## MT-NOTE-001：只确认本次提交的编辑版本

编辑器维护文档代次与编辑 revision，保存时冻结标题、正文、标签、文件位置、服务端版本及 operation ID。保存 A 期间继续键入 B，成功响应只确认 A：B 保留，未保存标记与离开提醒继续有效，界面提示“上次提交已保存，仍有未保存修改”。第二次保存使用已确认的服务端版本提交 B。

POST 成功后先推进文档身份和 CAS 基线，再读取原文与列表。读取失败保留草稿和已确认版本，刷新重试只读取结果。网络中断导致写入结果未知时，重试使用原 operation ID 和原内容确认同一次提交，后续编辑不会混入旧回执。切换文档、引用或资料库后，过期响应不能改写新的编辑器。打开跨库共享正文时，编辑器等待目标库的别名列表，分别读取该库的标题、标签和路径，避免沿用上一库的闭包数据。

## MT-KNOW-001：正文去重保留文件位置

普通 Markdown/TXT 导入与共享 ZIP 导入复用事务内路径注册。同一 owner 的相同正文仍可复用一个 document ID，但每个资料库的相对路径、标题、标签分别保存。路径按 Unicode NFC 规范化并以大小写无关的键检查冲突；隐藏路径、越界路径、不支持的扩展名和超长路径拒绝保存。

重复导入同路径同正文保持幂等。不同正文占用相同路径、同路径元数据发生变化时，需要打开该位置并确认当前版本后保存，原有 CAS 继续生效。并发争用同一路径时只允许一个事务成功，失败写入不留下正文或别名残留。

新资料库显式导入相同正文时保存自己的位置，不继承另一库的显示路径。列表按本库别名展开；导出清单使用每个位置自己的标题与标签，导出、另一 owner 导入再导出后保留目录与元数据。正文、版本和检索状态仍共享，编辑提示保留这一关系。

单请求回执给出输入文件、唯一正文、保留路径、新建正文等信息；文件夹界面使用 document ID 与路径集合统计本次输入，分别显示文件数、不同正文数、保留位置数。中途失败仍刷新已经成功的结果，不把去重正文数当成导入文件数。

## MT-ONBOARD-001：主动续做暂缓的初评

学生可以从学习记录中的既有初评入口主动继续。恢复接口校验当前 owner、run ID、题库与策略指纹，仅恢复兼容的同一 run，保留首次选项、已答题目与位置。完成三题后暂缓并重启，继续时仍从第四题开始；重复恢复幂等，不新增作答事件。

已完成的 run 保留原结果。旧 v1 run 只在当前题库和规则仍与原版本一致时兼容恢复；版本不兼容时解释原因并保留记录。暂缓后正常学习、重启或修改 API 配置不会自动恢复初评，其他学习记录也不会被清空。此轮实现限于兼容 run 的续做，多版本重测需要单独的产品与历史记录设计。

## 验收与复现

定向测试使用真实 FastAPI、WebSocket 和临时 SQLite 数据库，浏览器测试使用真实 React 界面与隔离 API／WebSocket 夹具。所有数据均为合成数据，没有访问真实学生数据库、调用付费模型、训练或更新模型权重。

```bash
python -m pytest tests/test_practice_response_modes.py tests/test_practice_options_atomic.py tests/test_knowledge_tracking_v2.py -q
python -m pytest tests/test_knowledge_path_aliases.py tests/test_question_packs.py tests/test_knowledge_workbench.py tests/test_community_file_import.py tests/test_knowledge_safety.py -q
python -m pytest tests/test_initial_assessment_resume.py tests/test_initial_assessment.py -q
cd web
npm test
npm run build
```

```bash
node web/scripts/smoke-practice-response-modes.mjs
node web/scripts/smoke-note-save.mjs
node web/scripts/smoke-initial-assessment-resume.mjs
```
