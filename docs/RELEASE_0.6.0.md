# MathTutor 0.6.0 发布说明

0.6.0 增加讲解公式核验、交互式数形结合、按教材组织的题库，以及模型费用和诊断记录。数据库由 0.5.0 的 023 升级至 024，新增逐轮诊断记录表；首次启动会先备份旧库，再迁移。

## 讲解与练习

- 模型生成的讲解逐式调用 `verify_math`。发现错误后请求一次修正；教学路径核验未通过时使用已验证的模板讲解。
- 普通聊天按句显示，只有数学公式闭合且核验通过的句子才进入流式预览；数学问题允许模型调用 `verify_math` 获取核验回执。
- 新增有理数边界的一元二次不等式，按精确区间比较学生答案，区分方向、端点和遗漏区间。
- 已诊断的错误类型参与下一道练习和提示选择。已映射的 DKT 技能在有本人作答后可调整一档帮助或难度，`MATHTUTOR_DKT_TEACHING=off` 可关闭；概率继续作为内部预测使用。

## 数形结合与题库

- 数形结合画布支持隐式曲线、参数曲线、极坐标曲线、不等式区域、点线面、切线、参数滑块、播放和动点轨迹，距离、角度与面积随参数更新。
- 「演示椭圆上的动点到焦点的距离」等已支持的表达可直接成图。模型通过 `draw_scene` 提交图形定义，由应用校验、计算和绘制；题目未完成时保持答案标记的展示限制。
- 题库按教材顺序组织 24 册、149 个单元和 359 个知识点；其中 68 个知识点有 449 道经过本地求解与核验的练习，42 个知识点有数形结合演示。
- 设置中的学段与年级决定题库默认展示范围；从题库可直接开始辅导。

## 费用、诊断与数据

- 支持自填模型输入、输出单价，设置每日金额或 token 预算；达到预算后，当天使用本地模板和检索回退。
- 逐轮诊断持久化保存失败率、延迟、token、费用和核验结果，达到样本门槛后提供阈值告警；开发者可在隔离数据库中回放会话。
- 可选 SQLCipher 整库加密在下次启动时转换数据库，转换前后检查完整性和记录数量。加密密钥存入系统凭据库；备份使用独立密钥，并可显示恢复密钥。上传的原始资料文件仍按现有文件方式保存。

## 安装与升级

- 修复 Windows CI 的备份调度测试竞态：等待备份文件、清单与保留策略全部完成，并验证备份期间的新唤醒请求能触发下一周期。
- 修复 WebSocket 断开时取消回执事务而遗留 SQLite 游标的问题：释放请求前等待回执和学习事件写入完成，避免多轮评测退出时数据库仍被占用。
- Windows x64 使用 NSIS 安装器，文件名为 `MathTutor-0.6.0-win-x64.exe`，附 blockmap 和 `SHA256SUMS-windows.txt`。该构建为未签名安装包，Windows 可能显示 SmartScreen 提示。
- 升级前在旧版中创建并核验一份备份，退出应用后安装新版；保留用户数据目录。首次启动会执行数据库迁移。若迁移失败，保留现场并使用旧版与已核验备份恢复。
- 安装包、平台验证结果及 SHA-256 以本次 GitHub Release 的实际附件和说明为准。
