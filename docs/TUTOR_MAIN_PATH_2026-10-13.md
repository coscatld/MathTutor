# 学生辅导主路径改进（2026-10-13）

基线：`C:\Users\lenovo\mt-release`，源码版本 0.4.4。下面的行为记录写于打包之前。正式版 0.4.4 安装包包含这条辅导路径，并在此之上用已训练的 DKT 权重调整映射技能的下一步提示和练习难度。概率不是掌握度。一步线性不等式，以及写全数字的应用题和少量数值几何句，会编译进既有题族后核验。

## 实际行为

空对话提供三道可点例题。进入题目后，对话中直接展示当前目标和「提示／我来写／看一步／再来一道」，练习邀请也在同一位置完成选择。按钮遵守服务端能力快照；「看一步」注明是相关例题示范。

「我来写」进入明确的本题作答模式，中间等式直接提交给判题路径，避免被反问是步骤还是新题。学生可以切回提问；换题、权限撤销或添加图片会退出这个模式，失败时保留草稿。

正向「我懂了」会自动进入一道经过求解器和验证器检查的同题族检查题。原题保留，检查题做对后回到原题；学生也可以跳过检查。检查结果记为诊断证据，不把原题判完成，不写成首次独立做对或旧版掌握度。「我不是不懂」和引用他人的话不会自动开检查。

错因文案只使用验证器实际支持的错误类别，例如「移项或常数处理没有保持等式相等」。两个不同题目的首次独立错误能让后续提示拆得更细，并选择对应运算结构的练习。它不会猜成学生「漏变号」，也不会由模型填写掌握概率。

超范围题会保留原来的请求，提供一道独立验证的相关基础练习。关系说明指出这道练习覆盖什么、原题哪些条件尚未核验。学生点击「练这道题」后才切换；解析失败的文字题也能保存这个入口，刷新后仍可使用。

自由生成的数学讲解，以及通过披露检查但没有逐句数学核验的模型讲解，都显示「本段讲解未经逐句数学核验」。这个说明与正文一起持久化，重放和重启后仍在。普通短寒暄保留自然文案；寒暄中出现数学断言仍需显示说明。完整模板中的数学材料来自既有验证流程。

生成器报告截断、续写接缝不确定或公式明显未完成时，回答保持 `PARTIAL`，界面提示末尾公式和结论可能不完整并提供「继续讲完」。自由讲解的单次输出预算调整为 2048 token，总预算和调用次数仍受既有运行时限制。续写使用保存的原始回答，不把附加的相关练习文案拼进半句公式。

## 能力边界

可逐步核验的题族包括四则运算、整式、一元一次、一元二次、二元一次方程组，以及一步线性不等式。写全数字的应用题和少量数值几何句会编译成上述题族后再核验；缺数字的应用题、函数图像、含参数方程、三角方程和二次不等式仍走相关练习，不冒充原题解答。本次没有重新取得真实模型的表达质量验收，也没有真实学生学习效果数据。

模型包自身仍是 `mode = shadow`，不能自行授权教学。映射得上的技能会从已随包的 ASSISTments seed 29 权重量出概率，并可能改变下一步提示和练习难度；映射不上的技能概率仍为空。`learning_effect_verified` 保持 false。没有新增数据库迁移。
